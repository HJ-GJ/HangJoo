리스트의 복사는 어디까지 복사될까?

original과 copied의 관계를 바꾸고, 값을 수정하거나 내부 리스트를 교체해 보세요. 무엇이 공유되는지 눈으로 확인하는 학습용 시뮬레이션입니다. 이 페이지는 실제 Python 코드를 실행하지 않고 Python 리스트의 동작을 모델링합니다.

학습용 시뮬레이션 · Python 실행 아님

1. 어떤 방법으로 복사했나요?

두 변수 이름이 동일한 바깥 리스트를 가리킵니다.
2. 어떤 동작을 해볼까요?




original


copied




원본 객체 ID새로 생성된 객체 ID




original is copied
original[0] is copied[0]


핵심: 객체 ID 표시는 이해를 돕기 위한 기호이고 Python의 실제 메모리 주소가 아닙니다. 대입은 같은 바깥 객체, 얕은 복사는 다른 바깥 객체와 공유된 내부 객체, 깊은 복사는 이 예제에서 내부 리스트까지 별도 객체를 생성합니다.
