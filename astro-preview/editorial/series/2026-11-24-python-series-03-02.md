> **Python 리스트와 복사 · 2/4편**  
> append·insert·pop·remove와 for 순회로 리스트 데이터를 다루는 방법을 연습합니다.

## 2. 실습 · 리스트를 직접 다뤄보기

### 2-1. 요소를 추가하고 삭제하기

리스트는 할 일 목록처럼 항목이 계속 바뀌는 자료를 다루는 데 잘 어울립니다. 자주 쓰는 메서드 네 가지를 비교해 봅니다.

| 메서드 | 하는 일 | 반환값 |
| --- | --- | --- |
| `append(x)` | 마지막에 `x` 한 개 추가 | `None` |
| `insert(i, x)` | 인덱스 `i` 위치에 `x` 삽입 | `None` |
| `pop(i)` | 인덱스 `i`의 요소를 제거 | 제거한 요소 |
| `remove(x)` | 값 `x`와 같은 **첫 번째** 요소 제거 | `None` |

**마지막에 추가하기: `append()`**

```python
tasks = ["Python 공부", "운동"]
tasks.append("독서")
print(tasks)
```

**예상 출력**

```text
['Python 공부', '운동', '독서']
```

`append()`는 **기존 리스트를 직접 변경**합니다. 새로운 리스트를 반환하지 않으므로 `tasks = tasks.append("독서")`처럼 작성하면 `tasks`에 `None`이 저장됩니다.

**원하는 위치에 삽입하기: `insert()`**

```python
tasks = ["Python 공부", "독서"]
tasks.insert(1, "운동")
print(tasks)
```

**예상 출력**

```text
['Python 공부', '운동', '독서']
```

인덱스 `1` 자리에 `운동`을 넣었으므로 기존의 `독서`가 뒤로 밀립니다. 기존 항목을 덮어쓰는 `tasks[1] = "운동"`과 다르게 **항목이 하나 늘어납니다.**

**꺼내면서 제거하기: `pop()`**

```python
tasks = ["Python 공부", "운동", "독서"]
finished = tasks.pop(0)
print(finished)
print(tasks)
```

**예상 출력**

```text
Python 공부
['운동', '독서']
```

`pop(0)`은 첫 번째 요소를 제거하면서 그 값을 돌려줍니다. 인덱스를 생략한 `pop()`은 **마지막 요소**를 꺼냅니다. 비어 있는 리스트에서 호출하면 `IndexError`가 발생합니다.

**값으로 찾아서 제거하기: `remove()`**

```python
tasks = ["Python 공부", "운동", "독서", "운동"]
tasks.remove("운동")
print(tasks)
```

**예상 출력**

```text
['Python 공부', '독서', '운동']
```

`remove()`는 위치가 아니라 **값**으로 삭제합니다. 같은 값이 여러 번 등장해도 **처음 발견한 한 개만** 삭제하며, 찾는 값이 없다면 `ValueError`가 발생합니다.

### 2-2. 앞에서 배운 `for`로 리스트 순회하기

NO.02에서 배운 반복문을 리스트와 연결하면 모든 점수를 하나씩 처리할 수 있습니다. `for score in scores:`에서 `score`는 리스트에서 이번 차례에 꺼낸 요소입니다.

```python
scores = [85, 90, 78]

total = 0
for score in scores:
    total += score

print("합계:", total)
print("평균:", total / len(scores))
```

**예상 출력**

```text
합계: 253
평균: 84.33333333333333
```

`total = 0`으로 합계의 시작값을 준비합니다. `for`문 안에서는 `85`, `90`, `78`을 차례로 더해 `253`을 만들고, 반복문이 끝난 뒤 `len(scores)`인 `3`으로 나눕니다. 같은 계산은 `sum(scores) / len(scores)`로 짧게 작성할 수도 있습니다. **빈 리스트의 평균**은 `len(scores)`가 `0`이므로 별도의 예외 처리가 필요합니다.
