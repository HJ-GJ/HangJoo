> **Python 반복문 · 1/3편**  
> 반복문이 필요한 이유, for와 while의 차이, range()의 범위 규칙을 확인합니다.

앞선 `NO. 01-3`에서는 `if`로 **조건에 따라 다른 코드를 실행하는 방법**을 살펴봤습니다. 이번에는 같은 일을 여러 번 해야 하는 상황을 생각해 봅니다.

예를 들어 “안녕하세요”를 다섯 번 보여 주려면 `print("안녕하세요")`를 다섯 줄 적을 수도 있습니다. 하지만 100번, 1,000번 출력하려면 어떨까요? 같은 명령을 일일이 적는 방법은 수정하기 어렵고 실수하기도 쉽습니다.

이때 사용하는 것이 **반복문**입니다. 반복문을 사용하면 코드를 한 번만 적어 두고, 정해진 횟수만큼 또는 특정 조건이 유지되는 동안 계속 실행할 수 있습니다.

<span class="legacy-heading-anchor" id="개념--반복문은-왜-필요할까" aria-hidden="true"></span>
## 1. 개념 · 반복문은 왜 필요할까?

<span class="legacy-heading-anchor" id="한-줄의-코드를-여러-번-실행하기" aria-hidden="true"></span>
### 1-1. 한 줄의 코드를 여러 번 실행하기

가장 먼저 익힐 반복문은 `for`입니다. 일정한 범위에서 값을 하나씩 가져오거나, 리스트의 요소를 하나씩 꺼낼 때 많이 사용합니다.

~~~python
for number in range(3):
    print("안녕하세요", number)
~~~

**예상 출력**

~~~text
안녕하세요 0
안녕하세요 1
안녕하세요 2
~~~

코드를 부분별로 읽어 봅니다.

- **`for`:** 값을 하나씩 가져오면서 아래 코드를 반복하겠다는 뜻입니다.
- **`number`:** 이번 차례에 가져온 값을 담을 변수 이름입니다. 처음에는 0, 다음에는 1, 마지막에는 2가 됩니다.
- **`in range(3)`:** 반복할 때 차례대로 꺼낼 0부터 2까지의 정수를 만듭니다.
- **`:`와 들여쓰기:** 반복할 코드의 시작과 범위를 나타냅니다.

이 코드는 `print()`를 한 줄만 작성했지만 세 번 실행합니다. 같은 내용을 여러 번 복사한 것보다 **반복 횟수를 바꾸기 쉽다는 점**이 장점입니다.

<span class="legacy-heading-anchor" id="range3은-왜-0부터-시작할까" aria-hidden="true"></span>
### 1-2. range(3)은 왜 0부터 시작할까?

`range()`는 일정한 규칙에 따라 정수를 차례대로 만들어 주는 도구입니다. 처음 배울 때 가장 헷갈리는 부분은 **끝 숫자가 포함되지 않는다는 점**입니다.

| 작성한 코드 | 반복할 숫자 |
| --- | --- |
| `range(3)` | 0, 1, 2 |
| `range(1, 4)` | 1, 2, 3 |
| `range(1, 6, 2)` | 1, 3, 5 |
| `range(5, 0, -2)` | 5, 3, 1 |
| `range(3, 3)` | *(비어 있음 · 반복 안 함)* |

`range(시작, 끝, 간격)`은 **범위에 값이 있으면 시작값부터 간격만큼 이동하며, 끝값은 포함하지 않습니다.** 시작을 생략하면 `0`부터, 간격을 생략하면 `1`씩 증가합니다. `range(3, 3)`이나 `range(5, 1)`처럼 조건에 맞는 값이 없으면 한 번도 반복하지 않습니다.

~~~python
for number in range(1, 6):
    print(number, end=" ")
~~~

**예상 출력**

~~~text
1 2 3 4 5
~~~

*(참고: 각 `print()`마다 공백 한 칸을 붙이므로 실제 출력 문자열은 `'1 2 3 4 5 '`이며 마지막에 줄 바꿈이 없습니다.)*

여기서는 1부터 5까지 출력하기 위해 **끝을 6으로 설정**했습니다. `NO. 01-1`에서 배운 `end=" "`는 숫자를 줄을 바꾸지 않고 공백으로 구분해 보여 줍니다.

:::visual python-day2-loop-flow.svg | for는 숫자나 요소를 차례로 가져와 반복하고, while은 조건을 다시 확인하면서 반복합니다.

<span class="legacy-heading-anchor" id="for와-while은-어떤-차이가-있을까" aria-hidden="true"></span>
### 1-3. for와 while은 어떤 차이가 있을까?

`for`가 반복 가능한 값들을 하나씩 꺼내 처리한다면, `while`은 **조건이 참인 동안** 같은 코드를 실행합니다.

~~~python
count = 1

while count <= 3:
    print("현재 값:", count)
    count += 1
~~~

**예상 출력**

~~~text
현재 값: 1
현재 값: 2
현재 값: 3
~~~

실행 순서를 천천히 살펴봅니다. 처음에 `count`는 1이므로 `count <= 3`이 참입니다. 화면에 1을 출력하고 `count += 1`로 2를 만듭니다. 다시 조건을 확인하고 같은 과정을 반복한 뒤 `count`가 4가 되면 조건이 거짓이므로 끝납니다.

여기서 `count += 1`은 `count = count + 1`을 짧게 쓴 것입니다. **조건이 언젠가는 거짓이 되도록 값을 바꾸는 코드**가 없으면 반복이 끝나지 않을 수 있습니다.

정리하면 **숫자나 리스트를 차례로 순회할 때 `for`**, **조건을 계속 확인하며 반복할 때 `while`**을 먼저 떠올려 보면 좋습니다. 이어지는 2편(`NO. 02-2`)에서는 `for`와 `while`로 합계를 누적하고 리스트를 순회하는 실습을 진행합니다.
