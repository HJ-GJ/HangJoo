> **Python 리스트와 복사 · 4/4편**  
> 인덱스·메서드·중첩 리스트에서 발생하는 실수를 해결하고 점수 관리 예제로 정리합니다.

## 3. 확인 · 실수하기 쉬운 부분

### 3-1. 인덱스와 슬라이싱의 경계

```python
numbers = [10, 20, 30]

# print(numbers[3])  # IndexError: 존재하지 않는 위치
print(numbers[1:3])
print(numbers[100:200])
```

**예상 출력**

```text
[20, 30]
[]
```

인덱싱은 범위를 벗어나면 오류를 내지만, **슬라이싱으로 범위 밖을 선택하면 가능한 범위만 반환**합니다. `[100:200]`처럼 해당 구간에 아무 값도 없다면 빈 리스트가 나옵니다. `numbers[::0]`처럼 간격을 `0`으로 지정하면 `ValueError`가 발생하므로 조심해야 합니다.

### 3-2. 메서드의 반환값과 제거 대상

```python
numbers = [10, 20]
result = numbers.append(30)

print(result)
print(numbers)
```

**예상 출력**

```text
None
[10, 20, 30]
```

`append()`는 리스트를 수정하고 `None`을 반환하므로, **수정된 리스트를 결과 변수에 다시 대입하지 않아야** 합니다. `pop()`은 위치를, `remove()`는 값을 기준으로 제거한다는 점도 구분해 두면 좋습니다.

### 3-3. 중첩 리스트를 만들 때 같은 행을 반복해서 참조하는 실수

복사 개념은 2차원 리스트에서도 등장합니다. 다음 코드는 겉으로는 두 행을 만든 것처럼 보여도 **실제로는 같은 내부 리스트를 두 번 참조**합니다.

```python
board = [[0] * 3] * 2
board[0][0] = 1
print(board)
```

**예상 출력**

```text
[[1, 0, 0], [1, 0, 0]]
```

첫 행만 바꾼 것 같은데 둘째 행도 변경되었습니다. 서로 독립적인 행이 필요하다면 **반복할 때마다 새로운 내부 리스트**를 만들면 됩니다.

```python
board = [[0] * 3 for _ in range(2)]
board[0][0] = 1
print(board)
```

**예상 출력**

```text
[[1, 0, 0], [0, 0, 0]]
```

여기서 `[0] * 3`은 각각의 행 안에 정수 `0` 세 개를 만드는 용도이고, 바깥쪽의 `for`가 **행마다 새 리스트를 생성**합니다. 리스트 컴프리헨션의 자세한 문법은 뒤의 학습에서 더 설명할 예정입니다.

### 3-4. 직접 풀어볼 작은 문제

1. `numbers = [5, 10, 15, 20, 25]`에서 **뒤에서 두 번째 요소**와 **앞의 세 요소**를 각각 출력해 보세요.
2. `tasks = ["코딩", "운동", "독서"]`에서 `pop()`을 이용해 맨 마지막 값을 꺼낸 뒤, 남은 리스트를 출력해 보세요.
3. `original = [[1, 2], [3, 4]]`를 얕은 복사한 다음 `copied[1][0] = 99`를 실행하면 원본은 어떻게 될까요? 같은 코드를 깊은 복사로 바꿀 때 결과를 먼저 예측해 보세요.

## 4. 정리 · 학습 점수 관리에 활용하기

### 4-1. 리스트를 이용한 작은 점수 관리 프로그램

지금까지 다룬 개념을 간단한 프로그램 하나로 연결해 봅시다. 아래 코드는 점수를 추가하고 일부를 선택한 뒤, 별도의 백업 리스트를 만들고 최솟값과 평균을 계산합니다.

```python
scores = [80, 95, 70, 88]

# 1. 새로운 점수 추가
scores.append(92)

# 2. 앞의 세 점수만 새 리스트로 선택
first_three = scores[:3]

# 3. 원본의 현재 상태를 백업
backup = scores.copy()

# 4. 최솟값과 평균 계산
lowest = min(scores)
average = sum(scores) / len(scores)

print("전체 점수:", scores)
print("앞의 세 점수:", first_three)
print("백업:", backup)
print("최저 점수:", lowest)
print("평균:", average)

# 5. 이후 원본을 변경해도 백업은 독립적
scores[0] = 100
print("수정 후:", scores)
print("백업 유지:", backup)
```

**예상 출력**

```text
전체 점수: [80, 95, 70, 88, 92]
앞의 세 점수: [80, 95, 70]
백업: [80, 95, 70, 88, 92]
최저 점수: 70
평균: 85.0
수정 후: [100, 95, 70, 88, 92]
백업 유지: [80, 95, 70, 88, 92]
```

처음에 `append(92)`로 다섯 번째 점수를 추가합니다. `scores[:3]`은 앞의 세 점수를 담는 별도 리스트를 만들고, `scores.copy()`도 바깥 리스트를 별도로 만듭니다. 최솟값은 `min()`, 합계는 `sum()`, 개수는 `len()`으로 계산하므로 평균은 `(80 + 95 + 70 + 88 + 92) / 5 = 85.0`입니다.

마지막 두 줄을 보면 `scores[0] = 100`으로 원본을 변경했지만 백업은 **수정 이전 값**을 유지합니다. 예제의 요소는 숫자이므로 얕은 복사로도 별도 백업이 가능했지만, 중첩된 가변 데이터를 다룰 때는 앞선 시리즈 3편에서처럼 내부 공유 여부를 확인해야 합니다. 여기의 `backup`은 메모리 안의 별도 리스트일 뿐, **파일에 영구 저장한 백업**은 아닙니다.

### 4-2. 핵심 개념 한눈에 정리하기

| 개념 | 기억할 점 |
| --- | --- |
| 리스트 `[]` | 여러 값을 순서대로 저장하며 요소 수정 가능 |
| `len()` | 리스트 안의 요소 개수 |
| 인덱싱 `a[i]` | 특정 위치 하나 선택, 첫 인덱스는 `0` |
| 슬라이싱 `a[start:end:step]` | 시작은 포함, 끝은 제외; 바깥 리스트는 새로 생성 |
| `append()` / `insert()` | 기존 리스트에 요소 추가 |
| `pop()` / `remove()` | 위치 기준 / 값 기준으로 제거 |
| `b = a` | 새 리스트가 아니라 같은 객체 참조 |
| `a == b` / `a is b` | 값 비교 / 객체 동일성 비교 |
| `a.copy()` 또는 `a[:]` | 얕은 복사: 바깥 리스트는 새로, 중첩 객체 참조는 공유 |
| `copy.deepcopy(a)` | 일반적인 중첩 가변 리스트까지 새로 복사 |

리스트에서 가장 중요한 것은 메서드 이름을 외우는 것보다 **어떤 동작이 기존 객체를 바꾸고, 어떤 동작이 새 객체를 만드는지** 이해하는 것입니다. 이 원리를 익혀 두면 다음에 함수 인자, 2차원 리스트, 클래스의 속성, 데이터 처리 코드를 배울 때도 예상하지 못한 값 변경을 더 쉽게 찾아낼 수 있습니다.

다음 글에서는 `for`문으로 리스트를 가공하는 방법과 **리스트 컴프리헨션**처럼 반복해서 새 리스트를 만드는 표현을 더 자세히 살펴볼 수 있습니다.
