> **Python 반복문 · 3/3편**  
> 반복 종료와 건너뛰기의 차이를 배우고 무한 반복을 피하는 방법을 확인합니다.

2편(`NO. 02-2`)에서는 `break`로 반복을 멈추는 방법을 살펴봤습니다. 이번에는 **`break`와 `continue`의 차이**를 비교하고, `while`에서 자주 겪는 무한 반복 실수를 확인한 뒤 시리즈 전체를 정리합니다.

<span class="legacy-heading-anchor" id="확인--break와-continue-흔한-실수" aria-hidden="true"></span>
## 1. 확인 · break와 continue, 흔한 실수

<span class="legacy-heading-anchor" id="break와-continue는-서로-달라요" aria-hidden="true"></span>
### 1-1. `break`와 `continue`의 차이

`break`는 **가장 안쪽의 반복문을 즉시 종료**합니다. 반면 `continue`는 **이번 차례의 남은 코드를 건너뛰고 다음 반복으로 넘어갑니다.** (`while`에서는 조건을 다시 확인합니다.)

~~~python
for number in range(1, 6):
    if number == 3:
        continue
    print(number)
~~~

**예상 출력**

~~~text
1
2
4
5
~~~

숫자 3을 만났을 때 `continue`가 실행돼 그 차례의 `print(number)`만 건너뜁니다. 반복은 끝나지 않으므로 4와 5는 그대로 출력됩니다.

이번에는 같은 자리에 `break`를 사용해 봅니다.

~~~python
for number in range(1, 6):
    if number == 3:
        break
    print(number)
~~~

**예상 출력**

~~~text
1
2
~~~

3을 만나자 반복문 자체가 끝나기 때문에 4와 5는 출력되지 않습니다.

<span class="legacy-heading-anchor" id="while에서-가장-주의할-오류-끝나지-않는-반복" aria-hidden="true"></span>
### 1-2. `while`에서 무한 반복이 생기는 경우

`while`과 `continue`를 함께 사용할 때는 **`continue`를 만나기 전에 반복 변수가 갱신되는지** 특히 확인해야 합니다.

다음은 문제가 생기는 구조를 보여 주는 예시입니다. 이 코드는 `count`가 `3`에 도달하면 출력 없이 무한 반복하므로 **그대로 실행하지 마세요.**

~~~python
# 잘못된 예시: count가 3에 도달하면 무한 반복에 빠집니다.
count = 0

while count < 5:
    if count == 3:
        continue
    count += 1
~~~

`count`가 3이 되면 `continue` 때문에 아래의 `count += 1`이 실행되지 않습니다. 다시 조건을 확인해도 여전히 3이어서 같은 일이 끝없이 반복됩니다.

**수정한 코드**에서는 반복 변수를 먼저 증가시킨 뒤 건너뛸 숫자를 판단하고, 결과를 확인할 수 있도록 `print(count)`도 추가했습니다.

~~~python
count = 0

while count < 5:
    count += 1
    if count == 3:
        continue
    print(count)
~~~

**예상 출력**

~~~text
1
2
4
5
~~~

`continue`가 실행되더라도 이미 `count`를 증가시켰기 때문에 다음 조건 검사로 넘어갈 수 있습니다. 단, 모든 `while`에 이 형태만 쓰라는 뜻은 아닙니다. **`continue`가 실행되는 경로에서도 다음 조건 검사 전에 `count`가 갱신되는지** 확인하는 습관이 핵심입니다.

<span class="legacy-heading-anchor" id="반복할-때-자주-실수하는-부분" aria-hidden="true"></span>
### 1-3. 반복할 때 자주 실수하는 부분

**첫째, `range()`의 끝값을 포함한다고 착각하기.** `range(1, 5)`는 1부터 4까지입니다. 5까지 필요하다면 `range(1, 6)`을 사용합니다.

**둘째, 들여쓰기를 잘못하기.** 반복할 코드는 `for`나 `while` 아래에 들여써야 합니다. 반복이 끝난 후 한 번만 실행할 코드는 반복문 바깥에 둡니다.

**셋째, `while`의 종료 조건을 생각하지 않기.** 조건이 계속 참이고 `break`도 실행되지 않으면 반복이 끝나지 않을 수 있습니다. 반복 변수의 증가·감소와 종료 조건을 함께 확인해야 합니다.

<span class="legacy-heading-anchor" id="직접-풀어-볼-작은-문제" aria-hidden="true"></span>

## 2. 정리 · Python 반복문 시리즈 정리

이번 **Python 반복문 시리즈(1–3편)**에서 가장 중요한 것은 문법 기호 자체보다 **반복이 언제 시작되어 어떤 코드를 실행하고 언제 끝나는지 흐름을 이해하는 것**입니다.

- **`for`** — 정수의 범위나 리스트 요소를 하나씩 순회할 때 사용합니다.
- **`range()`** — 범위에 값이 있으면 시작값부터 간격만큼 차례대로 정수를 만들며, 끝값은 포함하지 않습니다.
- **`while`** — 조건이 참인 동안 반복합니다. 끝나는 조건을 꼭 생각해야 합니다.
- **`break`** — 가장 안쪽의 반복문을 즉시 종료합니다.
- **`continue`** — 이번 차례의 나머지 코드를 건너뛰고 다음 반복으로 넘어갑니다.
- **들여쓰기** — 어느 코드가 반복되는지를 결정합니다.
