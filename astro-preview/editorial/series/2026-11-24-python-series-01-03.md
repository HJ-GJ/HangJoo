## 1. 확인 · 연산자와 조건문

<span class="legacy-heading-anchor" id="연산자로-계산하기" aria-hidden="true"></span>
### 1-1. 연산자로 계산하기

| 기호 | 의미 | 예시와 결과 |
| --- | --- | --- |
| `+` | 더하기 | `7 + 3` → `10` |
| `-` | 빼기 | `7 - 3` → `4` |
| `*` | 곱하기 | `7 * 3` → `21` |
| `/` | 나누기 | `7 / 2` → `3.5` |
| `//` | 내림한 몫 | `7 // 2` → `3` |
| `%` | 나머지 | `7 % 2` → `1` |
| `**` | 거듭제곱 | `2 ** 3` → `8` |

`//`는 양수 계산에서 보통 정수 몫처럼 보이지만, 정확히는 아래쪽(음의 무한대 방향)으로 내림합니다. 예를 들어 `-7 // 3`의 결과는 `-3`입니다.

<span class="legacy-heading-anchor" id="와-는-다릅니다" aria-hidden="true"></span>
### 1-2. `=`와 `==`의 차이

`=`는 **대입**, `==`는 **두 값이 같은지 비교**하는 기호입니다. 비교 결과는 `True` 또는 `False`입니다.

~~~python
score = 80
print(score == 80)
print(score >= 90)
~~~

**예상 출력**

~~~text
True
False
~~~

<span class="legacy-heading-anchor" id="if는-언제-사용할까" aria-hidden="true"></span>
### 1-3. if는 언제 사용할까?

`if`는 어떤 조건이 참일 때만 코드를 실행하는 **조건문**입니다. Python은 **콜론(`:`)과 들여쓰기**로 코드를 묶습니다. 아래 예제에서는 분기를 연습하기 위해 기준값을 `20`으로 정했습니다.

~~~python
age = 26

if age >= 20:
    print("성인입니다.")

print("확인 종료")
~~~

**예상 출력**

~~~text
성인입니다.
확인 종료
~~~

첫 번째 `print()`는 조건이 참일 때만, 들여쓰지 않은 마지막 `print()`는 조건과 상관없이 실행됩니다.

:::visual python-day1-branch-flow.svg | if는 조건에 따라 실행할 코드의 경로를 선택합니다.

`else`를 사용하면 조건이 거짓일 때 실행할 코드를 정할 수 있습니다.

~~~python
score = 55

if score >= 60:
    print("합격입니다.")
else:
    print("다음에 다시 도전해 봅시다.")
~~~

**예상 출력:** `다음에 다시 도전해 봅시다.`

`elif`는 앞의 조건이 거짓일 때 다음 조건을 차례로 검사합니다.

~~~python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

print(grade)
~~~

**예상 출력:** `B`

`if`부터 위에서 아래로 조건을 검사해 **처음으로 참이 된 블록 하나만 실행하고, 뒤의 조건은 검사하지 않습니다.** 모든 조건이 거짓이면 `else` 블록이 실행되므로 **조건을 작성한 순서**도 중요합니다. `and`는 두 조건을 함께 만족하는지, `or`는 둘 중 하나라도 만족하는지 확인할 때 사용합니다. `not`은 참과 거짓을 반대로 바꿉니다. 처음에는 조건 하나부터 연습한 뒤 조합해 보세요.

<span class="legacy-heading-anchor" id="직접-확인할-네-가지-질문" aria-hidden="true"></span>
### 1-4. 시리즈 전체 복습: 직접 확인할 네 가지 질문

1–3편에서 배운 내용을 스스로 점검해 보세요.

1. `print("Hello", "World", sep="-")`는 무엇을 출력할까요?
2. `input()`으로 받은 숫자에 바로 `1`을 더하면 왜 문제가 될까요?
3. `score = 75`일 때 `if score >= 80:` 아래의 코드는 실행될까요?
4. `=`와 `==`의 역할을 설명할 수 있나요?

<details>
<summary>확인 답안 보기</summary>

1. `Hello-World`가 출력됩니다. (`sep="-"`가 두 값 사이를 `-`로 연결합니다.)
2. `input()`의 반환값은 문자열(`str`)이므로 정수 `1`을 바로 더하면 `TypeError`가 발생합니다. `int()`로 먼저 변환해야 합니다.
3. 실행되지 않습니다. `75 >= 80`은 `False`이기 때문입니다.
4. `=`는 오른쪽 값을 왼쪽 변수 이름에 대입하고, `==`는 두 값이 같은지 비교해 `True`/`False`를 반환합니다.

</details>

<span class="legacy-heading-anchor" id="처음에-자주-겪는-실수-세-가지" aria-hidden="true"></span>
### 1-5. 처음에 자주 겪는 실수 세 가지

**1. 입력받은 문자열을 숫자로 착각하기**

~~~python
age = "26"
# print(age + 1)  # 문자열과 정수를 더하므로 TypeError
print(int(age) + 1)
~~~

**예상 출력:** `27`

오류가 나는 코드는 주석 처리했습니다. 숫자처럼 보이는 입력도 **문자열인지 먼저 확인**해 보세요.

**2. 대입(`=`)과 비교(`==`)를 혼동하기**

~~~python
score = 90

if score == 90:
    print("90점입니다.")
~~~

**예상 출력:** `90점입니다.`

`score = 90`은 이름 `score`에 값 `90`을 대입하는 문장이고, `score == 90`은 두 값이 같은지 확인하는 비교식입니다.

**3. 들여쓰기 실수로 실행 범위가 달라지기**

~~~python
score = 50

if score >= 60:
    print("합격입니다.")

print("검사가 끝났습니다.")
~~~

**예상 출력:** `검사가 끝났습니다.`

첫 번째 출력은 조건이 거짓이므로 실행되지 않지만, 들여쓰지 않은 마지막 출력은 실행됩니다. Python에서는 들여쓰기 자체가 코드의 구조입니다.

## 2. 정리 · Python 처음 시작하기 시리즈 정리

이번 **Python 처음 시작하기 시리즈(1–3편)**에서는 **Python이 무엇인지**부터 시작해 **출력 → 변수·자료형 → 입력·형 변환 → 연산 → 조건문**까지 살펴봤습니다.

- **Python · 인터프리터 · VS Code:** 언어, 코드를 실행하는 프로그램, 코드를 작성하는 편집기
- **`print()`와 `input()`:** 화면에 출력하고 사용자 입력받기
- **변수와 자료형:** 값을 이름으로 다루고 숫자·문자열 구별하기
- **`int()`:** 숫자로 된 문자열을 정수로 바꾸기
- **`if`·`elif`·`else`:** 조건에 따라 다른 코드 실행하기

**복습해 볼 순서:** `print("Hello World!")` 작성 → 변수에 값 저장 → `input()`으로 입력받기 → `int()`로 형 변환 → `if`로 분기하기. 처음에는 이 흐름을 직접 손으로 작성해 보는 것으로 충분합니다.

같은 코드를 여러 번 실행하는 **반복문(`for`·`while`)**은 다음 시리즈(`NO. 02 Python 반복문`)에서 이어서 정리합니다.
