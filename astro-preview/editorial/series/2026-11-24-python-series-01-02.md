> 변수, 자료형, 사용자 입력과 형 변환을 작은 실습으로 확인합니다.

1편(`NO. 01-1`)에서는 `print()`로 값을 화면에 출력해 봤습니다. 이번에는 값을 이름으로 저장하는 **변수**, 값의 종류를 구분하는 **자료형**, 키보드 입력을 받는 **`input()`과 형 변환**을 살펴봅니다.

<span class="legacy-heading-anchor" id="실습--변수와-입력을-직접-다뤄보기" aria-hidden="true"></span>
## 1. 실습 · 변수와 입력을 직접 다뤄 보기

<span class="legacy-heading-anchor" id="변수는-무엇일까" aria-hidden="true"></span>
### 1-1. 변수는 무엇일까?

변수는 **값을 다시 사용하기 위해 붙인 이름**입니다. 처음에는 값을 담는 상자라고 생각해도 좋습니다. Python에서는 더 정확히 변수 이름이 객체를 참조한다고 설명합니다.

~~~python
name = "HangJoo"
age = 26

print(name)
print(age)
~~~

**예상 출력**

~~~text
HangJoo
26
~~~

`=`는 “같다”가 아니라 오른쪽 값을 왼쪽 이름에 연결하는 **대입**입니다. **변수 이름**은 숫자로 시작할 수 없고, `if`처럼 Python이 사용하는 예약어는 이름으로 사용할 수 없습니다. `age`와 `Age`는 대소문자가 달라 서로 다른 이름입니다.

<span class="legacy-heading-anchor" id="자료형은-왜-필요할까" aria-hidden="true"></span>
### 1-2. 자료형은 왜 필요할까?

숫자 `26`과 문자열 `"26"`은 비슷해 보여도 서로 다른 값입니다. Python은 이런 구분을 **자료형(type)**으로 표현합니다.

| 자료형 | 의미 | 예시 |
| --- | --- | --- |
| `int` | 정수 | `26`, `-3` |
| `float` | 실수(부동소수점 수) | `3.14` |
| `str` | 문자열 | `"Python"`, `"26"` |
| `bool` | 참·거짓 | `True`, `False` |

*(참고: `float`은 소수를 이진 부동소수점으로 표현하므로 `0.1` 같은 일부 소수는 내부적으로 근삿값으로 저장됩니다.)*

~~~python
print(type(26))
print(type("26"))
print(type(True))
~~~

**예상 출력**

~~~text
<class 'int'>
<class 'str'>
<class 'bool'>
~~~

`type()`으로 자료형을 확인할 수 있습니다. **따옴표로 둘러싼 숫자도 문자열**이라는 점이 뒤에 나올 입력 계산에서 중요합니다.

<span class="legacy-heading-anchor" id="입력을-받는-input" aria-hidden="true"></span>
### 1-3. 입력을 받는 input()

`input()`은 터미널에서 사용자가 한 줄을 입력하고 Enter를 누를 때까지 기다렸다가, 끝의 줄 바꿈을 뺀 입력값을 받아옵니다.

~~~python
name = input("이름을 입력하세요: ")
print("안녕하세요,", name)
~~~

**예시 입력:** `형주`

**예상 출력(`print` 결과):** `안녕하세요, 형주` *(실제 터미널에는 `이름을 입력하세요: 형주` 안내 문구와 입력값도 함께 표시됩니다.)*

그런데 `input()`으로 받은 값은 항상 **문자열(`str`)**입니다. 숫자를 입력하더라도 자동으로 정수로 바뀌지는 않습니다.

:::visual python-day1-input-flow.svg | 입력으로 받은 숫자는 문자열이므로 숫자 계산 전에 자료형을 바꿔야 합니다.

<span class="legacy-heading-anchor" id="형-변환-입력받은-나이에-1-더하기" aria-hidden="true"></span>
### 1-4. 형 변환: 입력받은 나이에 1 더하기

~~~python
age_text = input("나이를 입력하세요: ")
age = int(age_text)
print("내년에는", age + 1, "살")
~~~

**예시 입력:** `26`

**예상 출력(`print` 결과):** `내년에는 27 살`

한 줄씩 살펴보면 `input()`으로 문자열을 받고, `int()`로 정수로 변환한 다음 `+ 1`을 계산해 `print()`로 출력합니다. 즉, **입력 → 변환 → 계산 → 출력** 순서입니다.

`int("26")`은 정수 `26`으로 바꿀 수 있지만 `int("스물여섯")`은 숫자로 바꿀 수 없어 `ValueError`가 발생합니다. 문자열 `"26"`에 정수 `1`을 바로 더하면 `TypeError`가 발생합니다.

<span class="legacy-heading-anchor" id="작은-실습-두-숫자-더하기" aria-hidden="true"></span>
### 1-5. 작은 실습: 두 정수 더하기

~~~python
first = int(input("첫 번째 숫자: "))
second = int(input("두 번째 숫자: "))
print("합계:", first + second)
~~~

**예시 입력:** 첫 번째 `3`, 두 번째 `5`

**예상 출력(`print` 결과):** `합계: 8`

공백으로 구분된 두 정수를 한 줄로 입력받을 때는 `first, second = map(int, input().split())` 같은 방법도 사용합니다. 하지만 처음에는 `input()`으로 입력을 받고 `int()`로 변환하는 과정을 따로 익힌 뒤, 나중에 이런 단축 표현을 살펴보면 더 쉽습니다.

<span class="legacy-heading-anchor" id="작은-실습으로-다시-확인하기" aria-hidden="true"></span>
### 1-6. 작은 실습으로 다시 확인하기

입력과 변환을 이해했는지 확인하려면 숫자 대신 문자열을 넣었을 때의 동작도 비교해 보면 좋습니다.

~~~python
print("3" + "5")
print(3 + 5)
~~~

**예상 출력**

~~~text
35
8
~~~

첫 줄은 **문자열 이어 붙이기**이고, 두 번째 줄은 **정수 더하기**입니다. 같은 기호 `+`를 사용해도 자료형에 따라 하는 일이 달라집니다.

문자열 안에 변수 값을 넣어 출력할 때는 **f-string(`f`가 붙은 포맷 문자열)**을 활용할 수도 있습니다. 익숙하지 않다면 기본 `print()`부터 연습한 뒤 돌아와도 됩니다.

~~~python
name = "HangJoo"
age = 26

print(f"{name}의 나이는 {age}살입니다.")
~~~

**예상 출력:** `HangJoo의 나이는 26살입니다.`

이 예시에서 `{name}`과 `{age}` 자리에는 각 변수의 값이 들어갑니다. 이어지는 3편(`NO. 01-3`)에서는 이렇게 준비한 값을 **연산자로 계산·비교하고 `if` 조건문으로 분기하는 방법**을 살펴봅니다.
