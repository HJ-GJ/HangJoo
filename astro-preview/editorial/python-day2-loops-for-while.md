첫 글에서는 `if`로 **조건에 따라 다른 코드를 실행하는 방법**을 살펴봤습니다. 이번에는 같은 일을 여러 번 해야 하는 상황을 생각해 보겠습니다.

예를 들어 “안녕하세요”를 다섯 번 보여 주려면 `print("안녕하세요")`를 다섯 줄 적을 수도 있습니다. 하지만 100번, 1,000번 출력하려면 어떨까요? 같은 명령을 일일이 적는 방법은 수정하기 어렵고 실수하기도 쉽습니다.

이때 사용하는 것이 **반복문**입니다. 반복문은 코드를 한 번 적어 두고, 정해진 횟수만큼 또는 특정 조건이 유지되는 동안 실행하도록 도와줍니다.

## 개념 · 반복문은 왜 필요할까?

### 한 줄의 코드를 여러 번 실행하기

가장 먼저 익힐 반복문은 `for`입니다. 일정한 범위에서 값을 하나씩 가져오거나, 목록의 요소를 하나씩 꺼낼 때 많이 사용합니다.

~~~python
for number in range(3):
    print("안녕하세요", number)
~~~

**예상 출력**

~~~text
안녕하세요 0
안녕하세요 1
안녕하세요 2
~~~

코드를 부분별로 읽어 보겠습니다.

- **`for`:** 값을 하나씩 가져오면서 아래 코드를 반복하겠다는 뜻입니다.
- **`number`:** 이번 차례에 가져온 값을 담을 변수 이름입니다. 처음에는 0, 다음에는 1, 마지막에는 2가 됩니다.
- **`in range(3)`:** 반복할 때 사용할 0부터 2까지의 숫자 흐름을 만듭니다.
- **`:`와 들여쓰기:** 반복할 코드의 시작과 범위를 나타냅니다.

이 코드는 `print()`를 한 줄만 작성했지만 세 번 실행합니다. 같은 내용을 여러 번 복사한 것보다 **반복 횟수를 바꾸기 쉽다는 점**이 장점입니다.

### range(3)은 왜 0부터 시작할까?

`range()`는 일정한 규칙에 따라 숫자를 차례대로 다루는 도구입니다. 처음 배울 때 가장 헷갈리는 부분은 **끝 숫자가 포함되지 않는다는 점**입니다.

| 작성한 코드 | 반복할 숫자 |
| --- | --- |
| `range(3)` | 0, 1, 2 |
| `range(1, 4)` | 1, 2, 3 |
| `range(1, 6, 2)` | 1, 3, 5 |
| `range(5, 0, -2)` | 5, 3, 1 |

`range(시작, 끝, 간격)`에서 **시작**은 포함되고 **끝**은 포함되지 않습니다. 시작을 생략하면 0부터, 간격을 생략하면 1씩 증가합니다.

~~~python
for number in range(1, 6):
    print(number, end=" ")
~~~

**예상 출력**

~~~text
1 2 3 4 5
~~~

여기서는 1부터 5까지 출력하기 위해 **끝을 6으로 설정**했습니다. 첫 번째 글에서 배운 `end=" "`는 숫자를 줄바꿈 없이 공백으로 구분해 보여 줍니다.

:::visual python-day2-loop-flow.svg | for는 숫자나 요소를 차례로 가져와 반복하고, while은 조건을 다시 확인하면서 반복합니다.

### for와 while은 어떤 차이가 있을까?

`for`가 반복 가능한 값의 흐름을 하나씩 따라간다면, `while`은 **조건이 참인 동안** 같은 코드를 실행합니다.

~~~python
count = 1

while count <= 3:
    print("현재 값:", count)
    count += 1
~~~

**예상 출력**

~~~text
현재 값: 1
현재 값: 2
현재 값: 3
~~~

실행 순서를 천천히 살펴봅시다. 처음에 `count`는 1이므로 `count <= 3`이 참입니다. 화면에 1을 출력하고 `count += 1`로 2를 만듭니다. 다시 조건을 확인하고 같은 과정을 반복한 뒤 `count`가 4가 되면 조건이 거짓이므로 끝납니다.

여기서 `count += 1`은 `count = count + 1`을 짧게 쓴 것입니다. **조건이 언젠가는 거짓이 되도록 값을 바꾸는 코드**가 없으면 반복이 끝나지 않을 수 있습니다.

정리하면, **숫자나 목록을 차례로 순회할 때 `for`**, **조건을 계속 확인하며 반복할 때 `while`**을 먼저 떠올려 보면 좋습니다.

## 실습 · 숫자와 목록으로 반복해 보기

### for로 1부터 5까지 더하기

반복문이 유용한 이유는 단순 출력뿐 아니라 **계산 결과를 차곡차곡 누적할 수 있기 때문**입니다.

~~~python
total = 0

for number in range(1, 6):
    total += number

print("합계:", total)
~~~

**예상 출력**

~~~text
합계: 15
~~~

`total = 0`은 계산을 시작할 때 합계를 0으로 준비하는 코드입니다. 반복문 안에서 `total += number`가 실행될 때마다 새로운 숫자를 합계에 더합니다.

| 반복 차례 | number | total |
| --- | --- | --- |
| 첫 번째 | 1 | 1 |
| 두 번째 | 2 | 3 |
| 세 번째 | 3 | 6 |
| 네 번째 | 4 | 10 |
| 다섯 번째 | 5 | 15 |

처음에는 `total`이 왜 0이어야 하는지, 반복문 바깥의 `print()`가 왜 한 번만 실행되는지를 함께 살펴보세요. 들여쓰기 위치에 따라 출력 횟수가 달라집니다.

### 숫자가 아니라 목록의 값을 반복하기

반복 대상이 반드시 숫자일 필요는 없습니다. 여러 값을 순서대로 보관하는 **리스트(list)**도 반복할 수 있습니다.

~~~python
fruits = ["사과", "배", "귤"]

for fruit in fruits:
    print("과일:", fruit)
~~~

**예상 출력**

~~~text
과일: 사과
과일: 배
과일: 귤
~~~

`fruits`는 과일 세 개가 들어 있는 리스트입니다. `fruit`는 반복할 때마다 리스트에서 꺼낸 하나의 문자열을 가리킵니다. 리스트의 내부 구조와 수정 방법은 다음 글에서 자세히 다룰 예정이지만, 지금은 **여러 값에 같은 동작을 적용할 수 있다**는 점만 이해하면 충분합니다.

### while과 break로 반복 끝내기

반복을 언제 끝낼지 상황에 따라 결정하고 싶다면 `while` 안에서 `break`를 사용할 수 있습니다.

~~~python
count = 0

while True:
    count += 1
    print(count)

    if count == 3:
        break
~~~

**예상 출력**

~~~text
1
2
3
~~~

`while True`는 조건이 항상 참이므로 그대로 두면 계속 반복됩니다. 하지만 `count == 3`이 되는 순간 `break`를 실행해 반복문 전체를 끝냅니다.

실제 학습 코드에서는 입력값이 특정 숫자인지 확인한 후 종료하는 방식도 쓰입니다. 입력이 필요한 코드는 사용자가 입력해야 결과가 달라지므로, 여기서는 실행 흐름을 더 쉽게 확인할 수 있도록 **정해진 숫자 예제**로 살펴봤습니다.

## 확인 · break와 continue, 흔한 실수

### break와 continue는 서로 달라요

`break`는 **반복문 자체를 종료**합니다. 반면 `continue`는 **이번 차례의 남은 코드를 건너뛰고 다음 반복으로 넘어갑니다.**

~~~python
for number in range(1, 6):
    if number == 3:
        continue
    print(number)
~~~

**예상 출력**

~~~text
1
2
4
5
~~~

숫자 3을 만났을 때 `continue`가 실행돼 그 차례의 `print(number)`만 건너뜁니다. 반복은 끝나지 않으므로 4와 5는 정상적으로 출력됩니다.

이번에는 같은 자리에 `break`를 사용해 보겠습니다.

~~~python
for number in range(1, 6):
    if number == 3:
        break
    print(number)
~~~

**예상 출력**

~~~text
1
2
~~~

3을 만나자 반복문 자체가 끝나기 때문에 4와 5는 출력되지 않습니다.

### while에서 가장 주의할 오류: 끝나지 않는 반복

`while`과 `continue`를 함께 사용할 때는 **변수의 변화가 건너뛰어지지 않는지** 특히 확인해야 합니다.

다음은 문제가 생기는 구조를 보여 주는 예시입니다. 실제로 실행하면 반복이 끝나지 않을 수 있으니 **그대로 실행하지 마세요.**

~~~python
# 잘못된 예시: count가 3에서 멈출 수 있습니다.
count = 0

while count < 5:
    if count == 3:
        continue
    count += 1
~~~

`count`가 3이 되면 `continue` 때문에 아래의 `count += 1`이 실행되지 않습니다. 다시 조건을 확인해도 여전히 3이어서 같은 일이 반복됩니다.

**수정한 코드**에서는 반복 변수를 먼저 증가시키고, 그다음 건너뛸 숫자를 판단합니다.

~~~python
count = 0

while count < 5:
    count += 1
    if count == 3:
        continue
    print(count)
~~~

**예상 출력**

~~~text
1
2
4
5
~~~

`continue`가 실행되더라도 이미 `count`를 증가시켰기 때문에 다음 차례로 넘어갈 수 있습니다. 단, 모든 `while`에 이 형태만 쓰라는 뜻은 아닙니다. **반복 조건을 바꾸는 코드가 반드시 실행되는지** 확인하는 습관이 핵심입니다.

### 반복할 때 자주 실수하는 부분

**첫째, range()의 끝값을 포함한다고 착각하기.** `range(1, 5)`는 1부터 4까지입니다. 5까지 필요하다면 `range(1, 6)`을 사용합니다.

**둘째, 들여쓰기를 잘못하기.** 반복할 코드는 `for`나 `while` 아래에 들여써야 합니다. 반복이 끝난 후 한 번만 실행할 코드는 반복문 바깥에 둡니다.

**셋째, while의 종료 조건을 생각하지 않기.** 반복 변수의 증가·감소, `break` 실행 가능성, 입력 종료 조건을 빠뜨리면 끝나지 않는 프로그램이 됩니다.

## 정리 · 반복문에서 기억할 것

이번 글에서 가장 중요한 것은 문법 기호 자체보다 **반복이 언제 시작되고, 무엇을 실행하며, 언제 끝나는지** 이해하는 일입니다.

- **`for`** — 숫자의 범위나 여러 요소를 하나씩 순회할 때 사용합니다.
- **`range()`** — 시작은 포함하고 끝은 포함하지 않는 숫자 흐름을 만듭니다.
- **`while`** — 조건이 참인 동안 반복합니다. 끝나는 조건을 꼭 생각해야 합니다.
- **`break`** — 반복을 즉시 종료합니다.
- **`continue`** — 이번 차례의 나머지 코드를 건너뛰고 다음 반복으로 넘어갑니다.
- **들여쓰기** — 어느 코드가 반복되는지를 결정합니다.

처음에는 숫자를 출력하는 작은 예제로 시작해 **합계를 누적하는 연습 → 리스트 요소 순회 → 조건에 따른 종료** 순서로 넓혀 보면 좋겠습니다. 다음에는 반복할 값들을 담아 두는 **리스트와 문자열**을 더 자세히 살펴볼 수 있습니다.
