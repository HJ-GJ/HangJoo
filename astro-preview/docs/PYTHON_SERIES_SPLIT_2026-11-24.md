## 시리즈 구성

### NO.01 — Python 처음 시작하기
1. **01-1 Python이란? 첫 코드와 출력**: 프로그래밍 언어, Python, 실행 환경, VS Code, print
2. **01-2 변수·자료형·input() 이해하기**: 변수, 자료형, 입력, 형 변환, 작은 실습
3. **01-3 연산자와 if 조건문 배우기**: 계산/비교 연산자, if/else/elif, 확인 질문, 오류와 정리

### NO.02 — Python 반복문
1. **02-1 반복문과 range() 처음 배우기**: 반복문 개념, range 규칙, for/while 비교와 흐름도
2. **02-2 for·while로 직접 반복해 보기**: 누적 합계, 리스트 반복, while+break
3. **02-3 break·continue와 반복문 실수**: break/continue, 종료 조건, 실수, 복습

### NO.03 — Python 리스트와 복사
1. **03-1 리스트·인덱싱·슬라이싱**: 리스트 가변성, 인덱스, 슬라이스, 그림
2. **03-2 리스트에 추가·삭제하고 순회하기**: append/insert/pop/remove, for 순회
3. **03-3 참조·얕은 복사·깊은 복사**: is/==, 대입/복사, 중첩 리스트, 인터랙티브 실험
4. **03-4 리스트 실수와 점수 관리 실습**: 예외, 반환값, 중첩 행 참조, 학습 점수 계산과 정리
