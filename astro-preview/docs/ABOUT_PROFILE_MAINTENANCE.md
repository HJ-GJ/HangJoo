# HangJoo’s Lab About 페이지 수정 안내

About 페이지 소스: astro-preview/src/pages/about.astro

## 사진 추가
현재 공개 승인된 프로필 사진이 없으므로 HJ. 모노그램이 표시됩니다. 사용자가 **명시적으로 공개에 동의한 사진**만 넣으세요.

1. 사진을 정사각형 또는 세로형으로 준비하고 적절히 잘라 WebP로 저장합니다(권장 600~900px, 과도한 EXIF/위치 메타데이터 제거).
2. Astro 프로젝트의 public/assets/profile.webp 경로에 업로드합니다.
3. about.astro 파일 맨 위의 profileImage 변수를 null에서 다음 경로를 가리키게 변경합니다: base + 'assets/profile.webp'
4. PC/모바일에서 이미지 잘림, 대체 텍스트, 저작권, 공개 범위를 검수한 후 PR을 병합합니다.

프로필 사진이 등록되지 않아도 소개 페이지는 HJ. 모노그램으로 정상 작동합니다. 저장된 개인 사진이나 채팅에 올린 사진이 곧바로 공개 사용을 허락한 것은 아닙니다.

## 학력·경력·관심 분야 수정
- 학력·교육: about.astro의 '전공과 학습' 아래 about-fact-card 항목을 편집합니다.
- 경력·활동: '경험과 성장 과정'의 about-timeline-item 항목을 편집합니다.
- 관심 분야: about-interest-list 항목을 편집합니다.
- 프로젝트: '만들면서 배우는 기록' 카드에 실제 검증된 상태만 기재합니다.
- 확인되지 않은 학교명·학위·근무기관·직위·날짜는 임의로 기입하지 않습니다.

About 페이지 내용은 블로그 공개 대상이므로, 개인 정보와 공개 여부에 관한 **사용자 최종 승인 후** main 병합·배포합니다.
