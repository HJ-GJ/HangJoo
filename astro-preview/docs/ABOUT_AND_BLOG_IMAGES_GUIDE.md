# About 직접 수정 및 글 이미지 게시 가이드

기준: HangJoo's Lab Astro v4.2 검토 브랜치 · GitHub Pages 공개 저장소
작성: 2026-11-23

## 1. 내 소개 직접 수정하기

소개 내용은 코드와 분리된 아래 JSON 하나만 수정하도록 구성했습니다.

- **텍스트 파일:** `astro-preview/src/data/about-profile.json`
- **소개 페이지 레이아웃:** `astro-preview/src/pages/about.astro` (글만 고칠 때는 변경하지 않아도 됨)
- `hero.lead`: 한 줄 자기소개
- `hero.introBefore`, `hero.introStrong`, `hero.introAfter`: 두 번째 소개 문단
- `education`: 학력/교육 카드 목록, `title`과 `description` 수정
- `experience`: 경력/경험 항목 목록
- `interests`: 관심 분야 태그
- `projects`: 개인 프로젝트 소개 카드
- `closing`: 마지막 메시지
- `portrait`: 승인받은 프로필 이미지의 사이트 URL. 비워두면 HJ 모노그램 표시

### GitHub 웹에서 수정하기

1. GitHub 저장소 `HJ-GJ/HangJoo`에 로그인합니다.
2. 아직 PR #19를 승인하지 않았다면 브랜치 **feat/blog-navigation-about-editorial-v4-2**를 선택합니다. `main`에 직접 수정하면 배포될 수 있으므로 미리보기 브랜치에서 작업하세요.
3. `astro-preview/src/data/about-profile.json`을 열고 오른쪽 위 **연필(Edit this file)**을 누릅니다.
4. 문장을 수정한 뒤 **Commit changes**에서 새 작업 브랜치/PR을 선택하거나 검토 브랜치에 커밋합니다. 공개 전에 꼭 미리보기로 확인하세요.
5. JSON 문법 규칙: 모든 글자 값은 큰따옴표로 감싸고 항목 사이에 쉼표를 넣습니다. 마지막 항목 뒤에는 쉼표를 붙이지 않습니다. 이미지가 없다면 `"portrait": ""`를 유지하세요.

### 프로필 이미지 넣기

1. 사용자가 공개에 동의한 인물 사진만 선택합니다. 타인이 함께 찍힌 사진, 개인정보나 위치를 유추할 수 있는 배경은 확인 후 편집합니다.
2. 원본을 공개 저장소에 바로 넣지 말고 웹 공개용 4:5 또는 1:1 비율, 약 900–1200px, 용량이 작은 WebP/JPEG 파일로 내보냅니다.
3. `astro-preview/public/assets/profile/` 아래에 예: `portrait.webp`를 추가합니다.
4. JSON의 `portrait`를 `"/HangJoo/assets/profile/portrait.webp"`로 설정하고 PC·모바일에서 크롭을 확인합니다.
5. 공개 GitHub에 올린 파일은 URL뿐 아니라 원본 Git 이력으로도 접근할 수 있으므로 **공개 승인 후** 커밋합니다.

## 2. 구글 드라이브 사진 / AI 생성 이미지 넣기

- 사용자가 파일을 지정하고 웹 공개를 허락하면, 파일을 읽고 이미지 크기를 줄이고 포맷을 변환한 뒤 공개 블로그 소스에 넣을 수 있습니다.
- Google Drive **공유 URL을 그대로 본문 이미지 주소로 쓰지 않는 것**을 추천합니다. 권한·리다이렉트·다운로드 제한으로 표시되지 않을 수 있습니다.
- 사용자가 직접 올린 사진과 생성된 그림 모두 공개 전에 저작권/초상권/민감 정보/라이선스 여부를 확인합니다. 생성 이미지를 실제 행사 현장이나 게임 실제 화면처럼 오해하게 하지 않습니다.
- 기사 전용 위치: `astro-preview/public/assets/posts/<slug>/`
- 게시용 Markdown 예시:

```md
![리스트의 인덱스 0부터 4까지 표시한 학습 도식](/HangJoo/assets/posts/<slug>/list-index.webp)
*그림: 리스트 인덱싱 순서. 직접 제작한 설명 자료.*
```

## 3. 게임 리뷰 이미지 추천 구성

- 글 상단에 게임의 분위기를 보여주는 **가로형 대표 이미지 1장** (권장 16:9).
- 본문에는 직접 촬영한 게임 플레이 스크린샷 **2~4장**을 필요한 설명 옆에 두고, 각 이미지마다 짧은 캡션을 작성합니다.
- 조작감·UI를 설명할 때는 HUD/설정창 등 **정보가 잘 보이는 일부 확대 이미지**를 활용할 수 있습니다.
- 마지막에는 장단점/총평을 글로 정리하고 이미지는 읽는 흐름을 방해하지 않을 정도로 배치합니다.
- 가능하면 직접 촬영한 게임 화면을 쓰고, 해당 게임사의 스크린샷·팬 콘텐츠·상표 사용 규정을 확인합니다. 공식 홍보 이미지·다른 사람의 스크린샷·음원/트레일러는 권리·출처와 사용 허락을 먼저 확인해야 합니다.
- 모든 이미지에 내용 중심 대체 텍스트(alt)를 넣고, 2열 갤러리는 모바일에서 1열로 내려오게 만듭니다. 모바일에서는 전체 페이지로 넘겨 볼 수 있도록 확대 기능을 별도 검토합니다.
- Lottie는 게임의 실제 화면을 대신하는 것이 아니라 자체 제작한 평가/비교 그래프나 UI 전환 애니메이션에 선택적으로 사용합니다.

## 4. 승인 흐름

이미지 지정 → 원본 출처 및 공개 범위 확인 → 편집/용량·모바일 검수 → 검토용 PR → 사용자 최종 승인 → 공개 배포.

확인되지 않은 사용자 실제 활동, 리뷰 점수, 저작권 소유, 게임 화면 등은 임의로 만들어 쓰지 않습니다.
