## 1. 이론: 숫자를 담는 4가지 그릇 — 스칼라, 벡터, 행렬, 텐서

NumPy(`import numpy as np`)는 파이썬에서 대규모 숫자 배열을 빠르고 간결하게 다루기 위한 핵심 도구입니다. 수업 교재(`numpy.html` Part 01)에서 가장 먼저 정리한 개념은 숫자를 쌓아 올리는 **차원(`ndim`)**과 **모양(`shape`)**의 관계였습니다.

:::formula
스칼라 (0차원, Scalar) | s = np.array(5) → ndim=0, shape=() | 방향이나 줄이 없는 숫자 딱 한 개(예: 오늘 기온 23°C)입니다.
벡터 (1차원, Vector) | v = np.array([80, 90, 70]) → ndim=1, shape=(3,) | 숫자를 한 줄로 나열한 묶음(예: 학생 한 명의 국·영·수 점수)입니다.
행렬 (2차원, Matrix) | m = np.array([[80, 90, 70], [60, 85, 95]]) → ndim=2, shape=(2, 3) | 여러 줄을 위아래로 쌓은 표 형태이며 항상 (행 개수, 열 개수) 순서로 읽습니다.
텐서 (3차원 이상, Tensor) | t = np.zeros((3, 3, 3)) → ndim=3, shape=(3, 3, 3) | 행렬 여러 장을 겹쳐 놓은 입체 구조(예: 컬러 사진의 R·G·B 3장 겹침)입니다.
:::

배열을 자동으로 채워 만드는 생성 함수 6종(`zeros`, `ones`, `full`, `arange`, `linspace`, `random.rand`)을 연습할 때는 **모양(`shape`)을 전달하는 괄호 개수**와 **끝값 포함 여부**를 구분하는 것이 중요했습니다.

:::compare
### 파이썬 리스트 vs NumPy 배열 (`ndarray`)
- `lst = [1, 2, 3]`에서 `lst * 2`를 실행하면 리스트가 통째로 복사되어 `[1, 2, 3, 1, 2, 3]`이 됨
- 원소마다 2를 곱하려면 `[x * 2 for x in lst]`처럼 직접 반복문을 돌려야 함
- `np.zeros((2, 3))`, `np.ones((2, 3))`, `np.full((2, 3), 7)`은 모양을 튜플로 받으므로 **괄호가 두 겹**임
---
### NumPy 배열 생성 및 연산 규칙
- `arr = np.array([1, 2, 3])`에서 `arr * 2`를 실행하면 모든 칸에 2가 곱해져 `array([2, 4, 6])`이 됨
- `np.arange(0, 10, 2)`는 끝값 `10`을 **포함하지 않고** `[0, 2, 4, 6, 8]`을 만듦
- `np.linspace(0, 1, 5)`는 시작(`0`)과 끝(`1`)을 **모두 포함**해 정확히 5개로 균등 분할하며, `np.random.rand(2, 3)`은 **괄호 한 겹**만 씀
:::

```python
# title: numpy_part1_creation.py — 차원별 배열 생성과 생성 함수 6종 검증
# takeaway: zeros((2, 3))처럼 모양을 튜플로 묶어 괄호 두 겹을 쓰는 함수와, np.random.rand(2, 3)처럼 괄호 한 겹을 쓰는 함수를 구분해야 TypeError를 피할 수 있습니다.
import numpy as np

# 1) 스칼라, 벡터, 행렬 생성 및 ndim / shape 확인
s = np.array(5)
v = np.array([80, 90, 70])
m = np.array([
    [80, 90, 70],
    [60, 85, 95]
])
print("스칼라:", s.ndim, s.shape)  # 0 ()
print("벡터  :", v.ndim, v.shape)  # 1 (3,)
print("행렬  :", m.ndim, m.shape)  # 2 (2, 3) -> 2행 3열

# 2) 자주 쓰는 자동 생성 함수 비교
# 핵심: arange는 '간격(step)' 기준(끝 미포함), linspace는 '개수(num)' 기준(끝 포함)입니다.
arr_step = np.arange(0, 10, 2)       # [0, 2, 4, 6, 8]
arr_even = np.linspace(0, 1, 5)      # [0. , 0.25, 0.5 , 0.75, 1. ]
box_sevens = np.full((2, 3), 7)      # 2행 3열을 숫자 7로 채움
print("arange  :", arr_step)
print("linspace:", arr_even)
print("full    :\n", box_sevens)
```

## 2. 위치 접근(Indexing)과 부분 사각형 오려내기(Slicing)

NumPy의 인덱스가 `1`이 아니라 **`0`부터 시작하는 이유**는 "맨 앞 기준점에서 몇 칸 떨어져 있는가(거리)"를 뜻하기 때문입니다. 2차원 행렬에서는 대괄호 하나에 쉼표(`,`)로 행과 열을 함께 적어 **`m[행, 열]`(아래로 몇 칸 → 오른쪽으로 몇 칸)** 순서로 찾아갑니다.

:::formula
단일 원소 접근 | m[1, 2] → 1번 행(둘째 줄), 2번 열(셋째 칸) | 대괄호 두 개 m[1][2] 대신 쉼표 하나로 m[1, 2]처럼 쓰는 것이 NumPy 표준입니다.
행 전체 / 열 전체 | m[0, :] (0번 행 전체), m[:, 1] (1번 열 전체) | 콜론(:) 단독은 '처음부터 끝까지 전부'를 뜻합니다.
부분 행렬 슬라이싱 | m[1:3, 1:4] → 행은 1~2번, 열은 1~3번 오려내기 | 슬라이싱 a:b 에서 끝 번호 b는 항상 제외(exclusive)됩니다.
:::

## 3. 같은 자리끼리 연산과 브로드캐스팅(Broadcasting)

모양(`shape`)이 같은 두 행렬 `A`, `B`를 더하거나 곱하면(`A + B`, `A * B`) 정확히 **같은 위치에 있는 칸끼리** 계산됩니다. 특히 배열 전체에 숫자 하나(스칼라)를 더하거나 곱하면, 그 숫자가 모든 칸으로 자동 확산되어 계산되는 **브로드캐스팅(Broadcasting)**이 일어납니다.

```python
# title: numpy_part2_indexing_broadcasting.py — 2차원 부분 슬라이싱과 섭씨→화씨 브로드캐스팅
# takeaway: 행렬에서 A * B는 같은 자리끼리 곱하는 원소별 곱셈(Hadamard product)이며, 선형대수의 행렬곱(A @ B)과는 전혀 다른 연산입니다.
import numpy as np

# 3행 4열 행렬에서 가운데 부분 사각형 오려내기
grid = np.array([
    [10, 20, 30, 40],
    [50, 60, 70, 80],
    [90, 10, 11, 12]
])

# 핵심: 행 0:2 (0, 1번 행), 열 1:3 (1, 2번 열) 교차 영역만 2x2 행렬로 잘라냅니다.
sub_grid = grid[0:2, 1:3]
print("오려낸 2x2 부분 행렬:\n", sub_grid)  # [[20, 30], [60, 70]]
print("맨 마지막 열 전체   :", grid[:, -1])  # [40, 80, 12]

# 브로드캐스팅 실습: 섭씨(Celsius) 배열을 반복문 없이 화씨(Fahrenheit = C * 9/5 + 32)로 변환
celsius = np.array([0, 10, 20, 30, 100])
fahrenheit = celsius * 9 / 5 + 32
print("화씨 변환 결과      :", fahrenheit)  # [ 32.  50.  68.  86. 212.]
```

## 4. 최종적으로 내가 알아낸 내용

:::finding
### NumPy Part 1 (교재 01~03) 학습으로 내가 직접 정리한 핵심 포인트
- **`shape`의 `(3,)`과 `(1, 3)`은 다름:** 1차원 벡터 `[80, 90, 70]`의 모양은 콤마 뒤에 숫자가 비어 있는 `(3,)`이고, 대괄호를 두 번 감싼 `[[80, 90, 70]]`은 1행 3열짜리 2차원 행렬 `(1, 3)`입니다.
- **`arange`와 `linspace`는 문제 조건에 따라 골라 쓸 것:** "2칸씩 띄어라"처럼 **보폭(간격)**이 주어지면 `np.arange(시작, 끝, 간격)`을 쓰고, "구간을 정확히 5등분 점으로 나눠라"처럼 **점의 개수**가 중요하면 끝점까지 포함해 주는 `np.linspace(시작, 끝, 개수)`가 훨씬 직관적입니다.
- **2차원 슬라이싱 `m[a:b, c:d]`는 가로줄 범위와 세로줄 범위가 겹치는 사각형 영역임:** 머릿속으로 행 범위(`a`부터 `b-1`까지)에 형광펜을 긋고, 열 범위(`c`부터 `d-1`까지)에 세로로 형광펜을 그었을 때 두 번 겹치는 영역이 결과 행렬이 됩니다.
:::
