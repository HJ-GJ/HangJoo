## 1. 데이터 탐색(EDA)에서 발견한 시점 의존성과 데이터 누수 방지

파이썬 문법을 마친 뒤 진행한 데이터 분석·머신러닝 프로젝트에서는 총 **45,111건(17개 컬럼)**의 은행 정기예금 캠페인 데이터를 다뤘습니다. 가장 먼저 확인한 핵심 원칙은 **데이터 누수(Data Leakage) 차단**과 **시기별 환경 차이 분리**였습니다.

:::compare
### 흔히 범하는 분석 오류
- 통화가 끝난 뒤에야 기록되는 `duration`(통화 시간)을 입력 변수에 포함해 비현실적으로 높은 정확도를 얻음
- 가입률이 4.74%인 전반부(24,060건)와 19.48%인 후반부(21,051건)를 단순 합산해 상관관계를 인과로 착각함
---
### 올바른 실험 설계 (`Bank_Marketing_Analysis.md`)
- 연락 전에 이미 알고 있는 **사전 정보(인구통계 + 금융 잔액/대출 + 과거 캠페인 이력)**만 피처로 사용
- 전반부와 후반부 각각에서 **Lift(그룹 가입률 ÷ 동일 시기 평균 가입률) ≥ 1.25**를 동시에 만족하는지 교차 확인
:::

## 2. 시기별 Lift 수식과 세그먼트 검증 코드

특정 고객군의 가입률이 단순히 캠페인 후반부에 많이 몰려 있어서 높게 보인 것인지, 아니면 두 시기 모두에서 일관되게 높은지 판별하기 위해 시기별 Lift를 계산했습니다.

:::formula
시기별 Lift 정의 | Lift(G, period) = P(y=1 | G, period) / P(y=1 | period) | 1.0보다 크면 해당 시기 평균보다 가입 확률이 높은 유망 세그먼트입니다.
일관성 판정 기준 | Lift(G, 전반부) ≥ 1.25 AND Lift(G, 후반부) ≥ 1.25 | 두 시기 모두에서 최소 표본(100명 이상)과 Lift 기준을 통과한 세그먼트만 채택합니다.
:::

```python
# title: verify_segment_lift.py — 전·후반 시기별 세그먼트 Lift 계산
# takeaway: 전체 기간 평균만 보면 학생·은퇴자도 높아 보이지만, 전·후반을 분리해 둘 다 Lift >= 1.25를 만족하는 일관된 고가입 세그먼트는 '30세 미만' 그룹임을 확인할 수 있습니다.
segments = [
    ("30세 미만",     0.0652, 0.2583),
    ("학생",          0.0577, 0.3299),
    ("은퇴자",        0.0484, 0.3621),
    ("잔액 상위 25%", 0.0551, 0.2466),
    ("주택대출 없음", 0.0516, 0.2984),
]

base_early, base_late = 0.04738, 0.19481

# 핵심: 각 세그먼트가 전반부와 후반부 모두에서 Lift >= 1.25 기준을 통과하는지 계산합니다.
for name, rate_early, rate_late in segments:
    lift_early = rate_early / base_early
    lift_late = rate_late / base_late
    passed = "PASS (일관된 고가입)" if (lift_early >= 1.25 and lift_late >= 1.25) else "HOLD"
    print(f"{name:<12} | 전반 Lift: {lift_early:.3f} | 후반 Lift: {lift_late:.3f} -> {passed}")
```

## 3. 최종적으로 내가 알아낸 내용

:::finding
### Bank Marketing EDA 및 머신러닝 실습을 통해 직접 깨달은 핵심 원리
- **예측 시점에 알 수 없는 미래 정보(`duration`)는 모델 점수를 부풀리는 독약임:** 통화가 끝난 뒤에야 기록되는 통화 시간을 빼고 나니 AUC가 내려갔지만, 그것이야말로 실제 전화 걸기 전에 쓸 수 있는 진짜 예측 성능이었습니다.
- **전체 평균 하나만 믿으면 '심슨의 역설(시기별 착시)'에 속기 쉬움:** 후반부 캠페인 환경 자체가 전반부보다 가입률이 4.11배 높았기 때문에, 두 시기를 나눠서 각각 `Lift >= 1.25`를 검증한 끝에 진짜 유효 타깃(`30세 미만`)을 가려낼 수 있었습니다.
:::
