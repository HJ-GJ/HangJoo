1. 이론: 왜 엑셀 대신 Pandas(`DataFrame`, `Series`)를 쓰는가?

엑셀에서는 학생이 8명일 때 눈으로 보며 A반 학생만 골라 수학 평균을 낼 수 있지만, 데이터가 10만 줄이거나 매일 새 파일이 들어오면 손작업이 불가능해집니다. 수업 교재(Pandas_입문교재.html Part 01~02)에서는 똑같은 작업을 df.groupby('반')['수학'].mean() 단 한 줄로 재현 가능한 기록으로 남기는 Pandas의 핵심 구조를 다뤘습니다.

Series (1차원 열)
s = pd.Series([90, 80, 95], index=['국어', '영어', '수학'])
인덱스(이름표)가 붙어 있는 한 줄짜리 열 데이터입니다.
DataFrame (2차원 표)
df = pd.DataFrame({'이름': [...], '수학': [...]})
여러 개의 Series(열)가 같은 행 인덱스를 공유하며 나란히 합쳐진 표입니다.
탐색 도구 6종
head(n), tail(n), shape, columns, info(), describe()
표를 처음 열었을 때 모양, 열 이름, 결측치 여부, 숫자 통계를 즉시 확인합니다.

표를 처음 받아 들었을 때 확인하는 6가지 도구 중 df.shape와 df.columns는 함수가 아니라 속성(이름표)이므로 뒤에 괄호 ()를 붙이지 않는다는 점을 주의해야 합니다.

2. 비교: `df.loc`(이름표) vs `df.iloc`(번호표)와 조건 필터링 규칙

교재 Part 03~04에서 가장 강조된 핵심은 행과 열을 꺼내는 두 가지 방법(loc vs iloc)의 슬라이싱 끝 번호 포함 여부와, 다중 조건 필터링(&, |)의 괄호 규칙이었습니다.

`df.loc` (Label-based, 이름표 기준) 및 단일 열 선택

  • df.loc[행라벨, '열이름']처럼 눈에 적힌 이름표로 찾음
  • 슬라이싱 df.loc[0:3]은 끝 번호 3을 포함하여 0, 1, 2, 3번 총 4개 행을 가져옴
  • 열 하나를 꺼낼 때는 df['수학'](대괄호 1겹, Series), 여러 열을 꺼낼 때는 df[['이름', '수학']](대괄호 2겹, DataFrame)을 사용

`df.iloc` (Integer-location, 위치 번호 기준) 및 불리언 인덱싱

  • df.iloc[행번호, 열번호]처럼 무조건 0부터 시작하는 순서 번호로만 찾음
  • 슬라이싱 df.iloc[0:3]은 끝 번호 3을 제외하여 0, 1, 2번 총 3개 행만 가져옴
  • 다중 조건 필터링 시 파이썬 and/or 대신 &(둘 다)와 |(하나라도)를 쓰고, 각 조건을 반드시 소괄호 ( )로 감싸야 함

3. 실습: 8명 학생 성적표 탐색과 불리언 인덱싱 검증

수업 교재 전체에서 공통으로 사용한 8명 학생(민준, 서연, 도윤, 하은, 시우, 지안, 예준, 수아) 성적표를 직접 생성하고, loc·iloc 및 다중 조건 필터링(&, isin)을 실행해 결과를 검증했습니다.

실습 코드 pandas_part1_explore_and_filter.py — 8명 학생 성적표 loc/iloc 비교 및 조건 필터링 눌러서 보기접기 
import pandas as pd

df = pd.DataFrame({
    "이름": ["민준", "서연", "도윤", "하은", "시우", "지안", "예준", "수아"],
    "반":   ["A", "A", "B", "B", "A", "B", "A", "B"],
    "국어": [88, 92, 76, 85, 95, 70, 81, 90],
    "영어": [84, 95, 80, 89, 91, 75, 78, 93],
    "수학": [90, 87, 94, 78, 98, 65, 85, 88],
})

# 1) 표 기본 모양 확인 (shape와 columns는 괄호 없음!)
print("표 크기(행, 열):", df.shape)          # (8, 5)
print("열 이름 목록    :", list(df.columns))

# 2) loc vs iloc 슬라이싱 끝 번호 포함 여부 비교
print("loc[0:2] 행 개수 (끝 포함):", len(df.loc[0:2]))   # 3행 (0, 1, 2)
print("iloc[0:2] 행 개수(끝 제외):", len(df.iloc[0:2]))  # 2행 (0, 1)

# 3) 핵심: 불리언 인덱싱 — A반이면서 수학이 90점 이상인 학생 찾기
cond = (df["반"] == "A") & (df["수학"] >= 90)
print("A반 & 수학>=90:\n", df.loc[cond, ["이름", "반", "수학"]])

# 4) isin()으로 여러 후보 한 번에 찾기
picked = df[df["이름"].isin(["민준", "하은", "수아"])]
print("isin 선택 학생:", list(picked["이름"]))
기억할 핵심 · PYTHON
Pandas 다중 조건에서 (df['반'] == 'A') & (df['수학'] >= 85) 처럼 조건마다 괄호를 치지 않으면 연산자 우선순위 때문에 에러가 발생합니다.

4. 최종적으로 내가 알아낸 내용

MY KEY FINDINGS Pandas Part 1 (교재 01~04) 학습으로 내가 직접 정리한 핵심 포인트
  • 대괄호 안의 문자열은 '열 이름'이고, 슬라이싱이나 불리언 마스크는 '행 필터'임: df['수학']은 열을 고르지만, df[df['수학'] >= 90]은 조건이 True인 행만 남깁니다. 행과 열을 동시에 명확히 지정할 때는 df.loc[조건, ['이름', '수학']] 패턴으로 통일하는 것이 가장 읽기 좋습니다.
  • loc[0:3](4개)과 iloc[0:3](3개)의 차이는 '이름표'냐 '칸 번호'냐에서 비롯됨: loc는 '국어':'수학'처럼 양 끝 이름표를 모두 포함해야 자연스럽기 때문에 숫자 라벨에서도 끝을 포함하도록 설계되었습니다.
  • or 대신 .isin([...])을 쓰면 코드가 절반으로 줄어듦: 같은 열에서 후보 여러 개(이름 == '민준' | 이름 == '서연' | ...)를 찾을 때는 df['이름'].isin(['민준', '서연'])이 훨씬 깔끔하고 실수가 없습니다.
