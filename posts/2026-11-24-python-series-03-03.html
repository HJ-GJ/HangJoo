Python 리스트와 복사 · 3/4편
같은 객체를 참조하는 대입과 얕은·깊은 복사를 비교하고 실험실에서 직접 확인합니다.

앞선 1–2편에서는 한 변수 이름으로 리스트를 수정해 봤습니다. 그렇다면 같은 리스트에 이름을 하나 더 붙이면 어떻게 될까요? 이번 편에서는 대입(참조), 얕은 복사, 깊은 복사의 차이를 비교합니다.

1. 실습 · 참조와 복사

1-1. 대입은 복사가 아니다: 같은 객체를 가리키는 두 이름

먼저 다음 결과를 출력 전에 예상해 봅니다.

original = [10, 20, 30]
copied = original
copied[0] = 999

print(original)
print(copied)
print(original is copied)

예상 출력

[999, 20, 30]
[999, 20, 30]
True

copied = original은 새 리스트를 만드는 코드가 아닙니다. 두 변수 이름이 메모리의 같은 리스트 객체를 참조하게 합니다. 그래서 copied[0] = 999로 변경하면 original을 통해서도 같은 결과가 보입니다.

# copied = original 직후
original ──┐
           ├──> [10, 20, 30]  (같은 객체 한 개)
copied   ──┘

이때 original is copied는 True입니다. is는 두 표현식이 정확히 같은 객체를 가리키는지 검사합니다.

1-2. is와 ==: 같은 객체일까, 같은 값일까?

==는 두 객체의 값이 같은지, is는 두 표현식이 같은 객체를 가리키는지 확인합니다.

a = [10, 20]
b = a.copy()

print(a == b)
print(a is b)

예상 출력

True
False

a와 b의 내용은 [10, 20]으로 같지만, copy()가 새 리스트를 만들었기 때문에 두 리스트는 다른 객체입니다. 값의 동등성을 확인할 때는 보통 ==를 사용하고, 같은 객체인지 알아야 할 때 is를 사용합니다.

1-3. 얕은 복사: 바깥 리스트는 새로, 내부 참조는 공유

새로운 리스트를 만들 때는 copy()나 [:]를 사용할 수 있습니다. 이 방식은 **얕은 복사(shallow copy)**입니다. 바깥 리스트는 별도 객체가 되지만, 요소가 다른 리스트를 가리키고 있다면 그 내부 리스트 자체는 공유합니다.

original = [[10, 20], [30, 40]]
copied = original.copy()
copied[0][0] = 999

print(original)
print(copied)
print(original is copied)
print(original[0] is copied[0])

예상 출력

[[999, 20], [30, 40]]
[[999, 20], [30, 40]]
False
True

첫 번째 False는 바깥 리스트가 서로 다르다는 뜻입니다. 두 번째 True는 첫 번째 내부 리스트를 공유한다는 뜻입니다. 따라서 copied[0][0] = 999로 내부 리스트 안의 값을 바꾸면 원본에도 그 변화가 그대로 반영됩니다.

그렇다면 복사본의 첫 번째 내부 리스트를 통째로 교체하면 어떻게 될까요?

original = [[10, 20], [30, 40]]
copied = original.copy()
copied[0] = [999, 20]

print(original)
print(copied)

예상 출력

[[10, 20], [30, 40]]
[[999, 20], [30, 40]]

이번에는 copied[0]이라는 바깥 리스트의 한 칸을 다른 객체로 교체했습니다. 바깥 리스트가 서로 독립적이므로 원본의 첫 번째 칸은 바뀌지 않습니다. 이처럼 수정하는 대상이 바깥 리스트인지 내부 리스트인지에 따라 결과가 달라집니다.

1-4. 깊은 복사: 중첩된 리스트도 독립적으로

중첩된 가변 객체까지 독립적으로 복사할 필요가 있다면 표준 라이브러리 copy 모듈의 deepcopy()를 사용합니다.

import copy

original = [[10, 20], [30, 40]]
copied = copy.deepcopy(original)
copied[0][0] = 999

print(original)
print(copied)
print(original[0] is copied[0])

예상 출력

[[10, 20], [30, 40]]
[[999, 20], [30, 40]]
False

import copy는 복사 관련 함수를 담은 표준 라이브러리 모듈을 가져옵니다. copy.deepcopy(original)은 바깥 리스트뿐 아니라 첫 번째·두 번째 내부 리스트도 별도로 생성하기 때문에, copied[0][0] = 999가 원본에 영향을 주지 않습니다.

다만 deepcopy()가 모든 객체를 예외 없이 새로 생성한다는 뜻은 아닙니다. 변경 불가능한 객체는 그대로 공유할 수 있고, 파일·외부 연결 등의 일부 객체는 일반적인 방식으로 복사할 수 없습니다. 일반적인 중첩 리스트 예제에서는 내부의 가변 리스트까지 분리된다고 이해하면 충분합니다.

직접 실험해 보기: 아래 실험실에서 대입, 얕은 복사, 깊은 복사를 하나씩 선택해 보고, 내부 값 변경과 내부 리스트 교체를 각각 눌러 보세요. 어느 경우에 original이 바뀌는지 눈으로 확인할 수 있습니다.
