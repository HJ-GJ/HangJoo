Data & ML — 정기예금 가입 예측(Bank Marketing)과 시기별 Lift 검증

45,111건의 은행 마케팅 데이터를 분석하며 전체 평균의 함정(심슨의 역설·시기별 가입률 4.11배 차이)을 분리하고, 사전 정보만으로 상위 20% 타깃 고객을 선정하는 Lift 검증 과정을 정리합니다.

핵심 요약: 통화가 끝난 뒤에야 알 수 있는 통화 시간(duration) 변수를 모델에 넣으면 데이터 누수(Data Leakage)가 발생하므로, 실제 캠페인 의사결정 시점에 알 수 있는 사전 변수만 사용해야 합니다.

1. 데이터 탐색(EDA)에서 발견한 시점 의존성과 데이터 누수 방지

파이썬 문법을 마친 뒤 진행한 데이터 분석·머신러닝 프로젝트에서는 총 45,111건(17개 컬럼)의 은행 정기예금 캠페인 데이터를 다뤘습니다. 가장 먼저 확인한 핵심 원칙은 데이터 누수(Data Leakage) 차단과 시기별 환경 차이 분리였습니다.

흔히 범하는 분석 오류

  • 통화가 끝난 뒤에야 기록되는 duration(통화 시간)을 입력 변수에 포함해 비현실적으로 높은 정확도를 얻음
  • 가입률이 4.74%인 전반부(24,060건)와 19.48%인 후반부(21,051건)를 단순 합산해 상관관계를 인과로 착각함

올바른 실험 설계 (`Bank_Marketing_Analysis.md`)

  • 연락 전에 이미 알고 있는 사전 정보(인구통계 + 금융 잔액/대출 + 과거 캠페인 이력)만 피처로 사용
  • 전반부와 후반부 각각에서 Lift(그룹 가입률 ÷ 동일 시기 평균 가입률) ≥ 1.25를 동시에 만족하는지 교차 확인

2. 시기별 Lift 수식과 세그먼트 검증 코드

특정 고객군의 가입률이 단순히 캠페인 후반부에 많이 몰려 있어서 높게 보인 것인지, 아니면 두 시기 모두에서 일관되게 높은지 판별하기 위해 시기별 Lift를 계산했습니다.

시기별 Lift 정의
Lift(G, period) = P(y=1
G, period) / P(y=1
일관성 판정 기준
Lift(G, 전반부) ≥ 1.25 AND Lift(G, 후반부) ≥ 1.25
두 시기 모두에서 최소 표본(100명 이상)과 Lift 기준을 통과한 세그먼트만 채택합니다.
실습 코드 verify_segment_lift.py — 전·후반 시기별 세그먼트 Lift 계산 눌러서 보기접기 
segments = [
    ("30세 미만",     0.0652, 0.2583),
    ("학생",          0.0577, 0.3299),
    ("은퇴자",        0.0484, 0.3621),
    ("잔액 상위 25%", 0.0551, 0.2466),
    ("주택대출 없음", 0.0516, 0.2984),
]

base_early, base_late = 0.04738, 0.19481

# 핵심: 각 세그먼트가 전반부와 후반부 모두에서 Lift >= 1.25 기준을 통과하는지 계산합니다.
for name, rate_early, rate_late in segments:
    lift_early = rate_early / base_early
    lift_late = rate_late / base_late
    passed = "PASS (일관된 고가입)" if (lift_early >= 1.25 and lift_late >= 1.25) else "HOLD"
    print(f"{name:<12} | 전반 Lift: {lift_early:.3f} | 후반 Lift: {lift_late:.3f} -> {passed}")
기억할 핵심 · PYTHON
전체 기간 평균만 보면 학생·은퇴자도 높아 보이지만, 전·후반을 분리해 둘 다 Lift >= 1.25를 만족하는 일관된 고가입 세그먼트는 '30세 미만' 그룹임을 확인할 수 있습니다.
