Python 반복문 · 1/3편
반복문이 필요한 이유, for와 while의 차이, range()의 시작·끝을 이해합니다.

첫 글에서는 if로 조건에 따라 다른 코드를 실행하는 방법을 살펴봤습니다. 이번에는 같은 일을 여러 번 해야 하는 상황을 생각해 보겠습니다.

예를 들어 “안녕하세요”를 다섯 번 보여 주려면 print("안녕하세요")를 다섯 줄 적을 수도 있습니다. 하지만 100번, 1,000번 출력하려면 어떨까요? 같은 명령을 일일이 적는 방법은 수정하기 어렵고 실수하기도 쉽습니다.

이때 사용하는 것이 반복문입니다. 반복문은 코드를 한 번 적어 두고, 정해진 횟수만큼 또는 특정 조건이 유지되는 동안 실행하도록 도와줍니다.

1. 개념 · 반복문은 왜 필요할까?

1-1. 한 줄의 코드를 여러 번 실행하기

가장 먼저 익힐 반복문은 for입니다. 일정한 범위에서 값을 하나씩 가져오거나, 목록의 요소를 하나씩 꺼낼 때 많이 사용합니다.

for number in range(3):
    print("안녕하세요", number)

예상 출력

안녕하세요 0
안녕하세요 1
안녕하세요 2

코드를 부분별로 읽어 보겠습니다.

  • for: 값을 하나씩 가져오면서 아래 코드를 반복하겠다는 뜻입니다.
  • number: 이번 차례에 가져온 값을 담을 변수 이름입니다. 처음에는 0, 다음에는 1, 마지막에는 2가 됩니다.
  • in range(3): 반복할 때 사용할 0부터 2까지의 숫자 흐름을 만듭니다.
  • :와 들여쓰기: 반복할 코드의 시작과 범위를 나타냅니다.

이 코드는 print()를 한 줄만 작성했지만 세 번 실행합니다. 같은 내용을 여러 번 복사한 것보다 반복 횟수를 바꾸기 쉽다는 점이 장점입니다.

1-2. range(3)은 왜 0부터 시작할까?

range()는 일정한 규칙에 따라 숫자를 차례대로 다루는 도구입니다. 처음 배울 때 가장 헷갈리는 부분은 끝 숫자가 포함되지 않는다는 점입니다.

작성한 코드 반복할 숫자
range(3) 0, 1, 2
range(1, 4) 1, 2, 3
range(1, 6, 2) 1, 3, 5
range(5, 0, -2) 5, 3, 1

range(시작, 끝, 간격)에서 시작은 포함되고 끝은 포함되지 않습니다. 시작을 생략하면 0부터, 간격을 생략하면 1씩 증가합니다.

for number in range(1, 6):
    print(number, end=" ")

예상 출력

1 2 3 4 5

여기서는 1부터 5까지 출력하기 위해 끝을 6으로 설정했습니다. 첫 번째 글에서 배운 end=" "는 숫자를 줄바꿈 없이 공백으로 구분해 보여 줍니다.

1-3. for와 while은 어떤 차이가 있을까?

for가 반복 가능한 값의 흐름을 하나씩 따라간다면, while은 조건이 참인 동안 같은 코드를 실행합니다.

count = 1

while count <= 3:
    print("현재 값:", count)
    count += 1

예상 출력

현재 값: 1
현재 값: 2
현재 값: 3

실행 순서를 천천히 살펴봅시다. 처음에 count는 1이므로 count <= 3이 참입니다. 화면에 1을 출력하고 count += 1로 2를 만듭니다. 다시 조건을 확인하고 같은 과정을 반복한 뒤 count가 4가 되면 조건이 거짓이므로 끝납니다.

여기서 count += 1은 count = count + 1을 짧게 쓴 것입니다. 조건이 언젠가는 거짓이 되도록 값을 바꾸는 코드가 없으면 반복이 끝나지 않을 수 있습니다.

정리하면, 숫자나 목록을 차례로 순회할 때 for, **조건을 계속 확인하며 반복할 때 while**을 먼저 떠올려 보면 좋습니다.
