1. 이론: 파이썬 인터프리터와 변수·메모리, 자료형과 연산자

수업 교재([python] 01. 파이썬 기초.pdf)의 첫 파트는 "파이썬이 코드를 어떻게 읽고 메모리에 값을 저장하는가"에서 출발합니다. 파이썬은 사람의 언어(영어)와 유사한 직관적인 문법을 가지며, 소스코드를 통째로 번역한 뒤 실행하는 대신 한 줄씩 위에서 아래로 읽으며 즉시 실행하는 인터프리터(Interpreter) 언어입니다.

  • 콜론(:)과 들여쓰기(Indentation): 다른 언어의 중괄호({ }) 대신 :과 4칸 공백(Tab) 들여쓰기로 코드 블록의 종속 관계를 엄격하게 구분합니다.
  • IDE와 실행 환경: VS Code 같은 통합 개발 환경(IDE)은 코드 작성을 돕는 도구일 뿐이며, 실제 실행은 설치된 Python 인터프리터(Add python.exe to PATH)와 연결되어 .py 파일을 해석합니다.
  • 변수(Variable)와 메모리 주소: 컴퓨터는 데이터를 0x00000001... 같은 복잡한 메모리 주소에 저장합니다. 사람이 이 주소를 외울 수 없으므로 메모리 공간(상자)에 붙이는 이름표가 바로 변수이며, 등호(=)는 수학의 '같다'가 아니라 오른쪽 값을 왼쪽 변수의 메모리에 저장하는 대입(할당, Assignment) 연산자입니다.
변수명 작성 4대 규칙
영문 대소문자·숫자·밑줄(_)만 사용 / 숫자로 시작 불가(1st_name X) / 대소문자 구별(age ≠ Age) / 예약어(if, for, class 등) 사용 불가
가독성을 위해 소문자와 밑줄을 조합하는 스네이크 케이스(user_name)를 표준으로 사용합니다.
기본 자료형 4종과 확인
int(정수: 10, -3), float(실수: 3.14), str(문자열: "Hello"), bool(논리형: True, False) → type(x)로 확인
"26" + 1 은 문자열과 정수의 덧셈이라 TypeError가 발생하므로 int(), float(), str(), bool()로 명시적 형 변환(Type Casting)을 거쳐야 합니다.
표준 입출력 제어
print(값, sep=" ", end="\n") / a, b = map(int, input().split())
input()은 모든 입력을 항상 문자열(str)로 반환하므로 .split()으로 공백 분리 후 map(int, ...)으로 각 항목을 정수 변환합니다.
산술·비교·논리·멤버십 연산자
산술(+, -, *, /, //, %, **) / 비교(==, !=, >, <, >=, <=) / 논리(and, or, not) / 멤버십(in, not in)
일반 나눗셈(/)은 나누어떨어져도 항상 실수(float)를 반환하며 이진 부동소수점 오차가 생길 수 있으므로 정수 계산에는 몫(//)과 나머지(%)를 사용합니다.

기본 `input()` / 일반 나눗셈(`/`)과 단일 `if` 나열

  • input() 단독 호출 시 숫자를 입력해도 문자열("26")로 저장되어 산술 연산 시 TypeError 발생
  • 10 / 2는 5가 아니라 실수 5.0을 반환하며, 실수 연산에는 미세한 부동소수점 오차가 포함될 수 있음
  • if문을 여러 개 독립적으로 나열하면 앞 조건이 참이어도 아래 if문들을 끝까지 모두 검사하며, 마지막 else는 직전의 if 딱 하나와만 짝을 이룸

`map(int, input().split())` / 정수 연산(`//`, `%`)과 `if - elif - else`

  • 공백으로 구분된 한 줄 입력을 1) 문자열 입력 → 2) 공백 기준 분리 → 3) 각 요소에 int() 적용 3단계로 즉시 언패킹
  • //(정수 몫)와 %(나머지), **(거듭제곱)으로 오차 없는 정수 단위 분해 수행
  • if - elif - else는 위에서부터 순차 검사하다가 가장 먼저 참(True)이 되는 블록 딱 하나만 실행하고 전체 조건문을 빠져나옴

2. 실습: 몫(`//`)과 나머지(`%`)로 시간·자릿수 다루기

이론에서 배운 정수 몫(//)과 나머지(%)를 조합하면 복잡한 조건문 없이도 시·분 단위를 변환하거나 세 자리 정수의 각 자릿수를 분리해 재조립할 수 있습니다.

시·분 경과 계산
total = H * 60 + M + T → ((total // 60) % 24, total % 60)
시(hour)와 분(minute)을 모두 '분' 단위로 통일해 더한 뒤, 다시 60으로 나눈 몫과 나머지로 복원합니다.
세 자리 정수 뒤집기
a = N // 100, b = (N // 10) % 10, c = N % 10
백의 자리, 십의 자리, 일의 자리를 차례로 분리한 뒤 c * 100 + b * 10 + a 로 재조립합니다.
맨해튼 거리
dist = abs(y1 - y2) + abs(x1 - x2)
두 좌표 사이의 격자 이동 거리는 각 축 차이의 절댓값 합으로 구합니다.
실습 코드 2026-10-13/basics — 시·분 더하기와 세 자리 숫자 뒤집기 실습 눌러서 보기접기 
# 1) 현재 시각(H, M)에서 T분이 지난 뒤의 시각(24시간제) 구하기
H, M = 23, 40
T = 35

# 핵심: 전체 분(total)으로 통합한 뒤 60으로 나눈 몫에 % 24를 적용해 자정을 넘깁니다.
total = H * 60 + M + T
next_h = (total // 60) % 24
next_m = total % 60
print(f"{next_h}시 {next_m}분")  # 0시 15분

# 2) 세 자리 정수 뒤집기 및 자릿수별 곱셈
N = 472
hundreds = N // 100
tens = (N // 10) % 10
ones = N % 10
reversed_num = ones * 100 + tens * 10 + hundreds
print(f"{N} -> {reversed_num}")  # 472 -> 274
기억할 핵심 · PYTHON
단위 변환 문제는 가장 작은 단위(분, 초, 1의 자리)로 먼저 합산한 뒤 // 와 % 로 상위 단위를 복원하면 조건 분기 없이 깔끔하게 풀립니다.

3. 실습: 조건문(`if - elif - else` · 중첩 `if`)과 논리 연산자 결합

교재의 조건문 파트에서는 단일 if, 양자택일 if-else, 다중 분기 if-elif-else, 그리고 조건문 안에 또 다른 조건문이 들어가는 중첩 조건문(Nested if)을 다뤘습니다. 실제 문제 풀이에서는 더 좁고 특수한 조건을 if의 맨 위에 배치해야 아래쪽 일반 조건에 먼저 흡수되지 않습니다.

  • 윤년 판별 (leap_year.py): 400의 배수인지 먼저 확인(N % 400 == 0)한 뒤, 4의 배수이면서 100의 배수가 아닌 경우(N % 4 == 0 and N % 100 != 0)를 elif로 검사합니다.
  • 삼각형 종류 판별 (triangle_type.py): 세 변이 모두 같은 정삼각형(a == b == c)을 먼저 검사하고, 두 변만 같은 이등변삼각형(a == b or b == c or a == c)을 그다음에 두어야 정삼각형이 이등변삼각형으로 잘못 분류되지 않습니다.
  • 야간 소음 판정 (quiet_hours.py): 논리곱(and)과 논리합(or)을 함께 쓸 때는 연산자 우선순위 혼동을 막기 위해 반드시 소괄호 ( )로 범위를 묶어줍니다.
실습 코드 2026-10-13/conditionals — 윤년·삼각형·야간 소음 조건 판정 눌러서 보기접기 
def classify_year(year: int) -> str:
    if year % 400 == 0:
        return "Leap"
    elif year % 4 == 0 and year % 100 != 0:
        return "Leap"
    return "Normal"

def check_quiet_hours(crying: int, hour: int) -> str:
    # 핵심: 울고 있으면서(crying == 1) 동시에 야간 시간대(7시 이전 또는 20시 이후)인지 검사
    if crying == 1 and (hour < 7 or hour >= 20):
        return "조용히 해!"
    return "조용하군"

print(classify_year(2000), classify_year(1900), classify_year(2024))
print(check_quiet_hours(1, 22), check_quiet_hours(1, 14))
기억할 핵심 · PYTHON
복합 조건식에서 and 가 or 보다 우선순위가 높으므로, 시간 범위 조건 (T < 7 or T >= 20) 은 반드시 괄호로 감싸야 의도대로 동작합니다.

4. 최종적으로 내가 알아낸 내용

MY KEY FINDINGS 파이썬 기초 이론과 조건문 실습을 통해 직접 깨달은 핵심 원리
  • =는 '같다(==)'가 아니라 오른쪽 값을 왼쪽 변수 메모리에 넣는 할당 연산자임: input()은 무조건 문자열(str)을 돌려주므로 산술 계산 전에는 반드시 int()나 map(int, input().split())으로 형 변환(Type Casting)을 거쳐야 합니다.
  • 단위 변환은 최소 단위로 먼저 통일할 것: 시·분 계산에서 분 >= 60, 시 >= 24를 if문으로 각각 나눌 필요 없이, 전체를 '분(H * 60 + M + T)'으로 합산한 뒤 (total // 60) % 24와 total % 60을 쓰면 자정을 몇 번 넘어가도 한 줄로 해결됩니다.
  • 독립된 if 나열과 if - elif - else 체인은 완전히 다르게 동작함: 여러 if를 나란히 쓰면 앞 조건이 참이어도 뒤의 if들을 계속 검사하고 마지막 else는 바로 위 if에만 묶이지만, if - elif - else로 묶으면 가장 먼저 참이 된 특수 조건 딱 하나만 실행되고 즉시 종료됩니다.
