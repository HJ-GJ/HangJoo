1. 이론 — 파이썬 실행 과정과 변수·자료형

Python은 코드를 어떻게 실행할까?

Python은 인터프리터를 통해 프로그램을 실행하는 언어입니다. 다만 소스코드를 단순히 한 줄씩 읽어 즉시 수행한다는 설명은 정확하지 않습니다. 가장 널리 쓰이는 구현인 CPython은 일반적으로 소스코드를 바이트코드로 컴파일하고, Python 가상 머신이 이를 실행합니다. 입문 단계에서는 먼저 작성한 코드 → Python 실행 환경 → 결과라는 흐름을 이해하면 충분합니다.

VS Code는 코드 작성 도구이고 실제 실행은 Python 환경이 담당합니다. 실행 명령이 인식되지 않으면 설치와 PATH 설정을 확인합니다.

들여쓰기는 왜 중요할까?

Python은 중괄호 대신 들여쓰기로 코드 블록의 범위를 표현합니다. 조건문과 반복문처럼 새로운 블록을 시작하는 구문에서는 보통 콜론(:)을 사용합니다. 권장 스타일은 들여쓰기 한 수준마다 공백 4개이며, 탭과 공백을 섞으면 오류가 날 수 있습니다.

실습 코드 들여쓰기에 따라 실행 범위가 달라지는 예제 눌러서 보기접기 
score = 92

if score >= 90:
    print("합격 기준을 충족했습니다.")
    print("우수한 점수입니다.")

print("평가가 종료되었습니다.")

조건이 참이면 들여쓴 두 줄이 모두 실행됩니다. 마지막 print()는 조건문 밖에 있으므로 점수와 관계없이 실행됩니다. 들여쓰기 하나가 프로그램의 논리를 바꿀 수 있다는 점을 기억하세요.

변수는 값이 담긴 상자일까?

입문서에서는 변수를 ‘상자’라고 설명하곤 합니다. 직관적인 비유지만, Python에서는 변수 이름이 객체를 참조한다고 이해하는 편이 더 정확합니다. =는 수학적 동등성을 뜻하는 기호가 아니라 오른쪽 표현식을 평가한 결과를 왼쪽 이름에 연결하는 대입 구문입니다. 같은지 비교할 때는 ==를 사용합니다.

실습 코드 이름 바인딩과 자료형 확인 눌러서 보기접기 
age = 26
name = "HangJoo"
is_learning = True

print(age, type(age))
print(name, type(name))
print(is_learning, type(is_learning))

int는 정수, float는 부동소수점 수, str은 문자열, bool은 참·거짓을 표현합니다. 이 네 가지는 자주 쓰는 자료형이며, 리스트·딕셔너리 같은 컬렉션도 있습니다.

입력은 왜 숫자처럼 보이는데 계산되지 않을까?

input()이 반환하는 값은 언제나 문자열입니다. 숫자 26을 입력해도 "26"으로 받아들이므로 계산 전 변환이 필요합니다.

실습 코드 문자열 입력을 정수로 변환하기 눌러서 보기접기 
raw = "26"  # input()으로 입력받았다고 가정
age = int(raw)
print(age + 1)

예상 출력: 27

실제 사용자 입력을 받으려면 raw = input("나이를 입력하세요: ")로 바꿉니다. 단, int("스물여섯")은 ValueError를 발생시킵니다. 즉, 형 변환이 가능하다는 전제를 먼저 확인해야 합니다.

두 개의 숫자를 공백으로 구분해 입력받는 경우에는 다음과 같이 작성할 수 있습니다.

실습 코드 공백으로 구분된 두 정수 읽기 눌러서 보기접기 
# 예시 입력: 12 30
a, b = map(int, input().split())
print(a + b)

input()으로 한 줄을 문자열로 받은 뒤, split()으로 나누고, 각 조각에 int()를 적용합니다. 정확히 두 값을 넣지 않으면 언패킹 과정에서 오류가 발생하므로 입력 형식도 중요합니다.

연산자를 제대로 구분하기

/는 일반 나눗셈으로 결과가 float이고, //는 아래쪽 정수 방향으로 내림하는 몫, %는 나머지입니다. 양수에서 //는 흔히 정수 부분을 얻는 것으로 설명하지만 음수의 경우 단순히 소수 부분을 버리는 것과 다릅니다.

실습 코드 /, //, % 그리고 거듭제곱 비교 눌러서 보기접기 
print(10 / 2)
print(10 // 3)
print(10 % 3)
print(2 ** 3)
print(-7 // 3)

2. 기초 실습 — 시간 계산과 숫자 뒤집기

시각 계산: 23시 40분에서 35분 뒤는?

시와 분을 따로 더하면 자정이 넘어가는 경우를 처리하기 번거롭습니다. 이럴 때는 먼저 모두 분으로 바꾸고, 계산 후 다시 시와 분으로 분해합니다.

실습 코드 24시간제 시각 계산 눌러서 보기접기 
hour, minute = 23, 40
elapsed = 35

total_minutes = hour * 60 + minute + elapsed
next_hour = (total_minutes // 60) % 24
next_minute = total_minutes % 60
print(f"{next_hour}시 {next_minute}분")
기억할 핵심 · PYTHON
전체를 분으로 합산한 다음 // 와 % 로 시각을 복원합니다.

예상 출력: 0시 15분

먼저 23시간을 분으로 변환한 뒤 현재 분과 경과 시간을 더합니다. // 60은 총 시간(시)을 구하고 % 24는 하루가 지난 경우 24시간제로 되돌립니다. 마지막 % 60은 남은 분을 구합니다. 경과 시간이 하루를 넘더라도 시각을 계산할 수 있지만 며칠이 지났는지를 따로 알고 싶다면 추가 계산이 필요합니다.

세 자리 정수를 거꾸로 출력하기

472를 274로 바꾸려면 백의 자리, 십의 자리, 일의 자리를 분리해야 합니다.

실습 코드 정수의 자릿수 분해와 재조립 눌러서 보기접기 
number = 472

hundreds = number // 100
tens = (number // 10) % 10
ones = number % 10

reversed_number = ones * 100 + tens * 10 + hundreds
print(reversed_number)

예상 출력: 274

백의 자리 4, 십의 자리 7, 일의 자리 2를 각각 정수 계산으로 얻고 순서를 뒤집습니다. 이 예제는 세 자리 양의 정수를 전제로 하며, 120을 뒤집으면 정수 21이 되어 선행 0을 보존하지 않습니다. 숫자로 계산할지, 문자열로 표현할지에 따라 풀이법이 달라집니다.

3. 응용 실습 — 조건문으로 문제 해결하기

if, elif, else의 실행 순서

if는 조건이 참인지 평가합니다. elif는 앞선 조건이 거짓일 때 다음 조건을 검사하고, else는 앞선 조건이 모두 거짓일 때 실행합니다. 하나의 if·elif·else 체인에서는 처음 참인 분기 하나만 실행됩니다. 반면 독립된 여러 if는 각각 평가됩니다.

실습 코드 시험 점수에 따른 학점 분류 눌러서 보기접기 
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

print(grade)

예상 출력: B

85점은 90점 이상이 아니므로 첫 조건을 통과하지 못합니다. 두 번째 조건인 80점 이상을 만족해 B가 결정되고, 아래 분기는 더 이상 검사하지 않습니다. 여기서 score >= 70을 맨 위로 옮기면 85점도 C로 분류될 수 있어 분기 순서가 중요합니다.

윤년 판별: 4년마다 무조건 윤년일까?

윤년은 4로 나누어떨어지되 100으로 나누어떨어지는 해는 제외하고, 400으로 나누어떨어지는 해는 다시 포함합니다. 이 규칙을 논리 연산으로 합칠 수 있습니다.

실습 코드 그레고리력 윤년 판별 눌러서 보기접기 
def is_leap_year(year):
    return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)

for year in [2000, 1900, 2024, 2025]:
    print(year, is_leap_year(year))

예상 출력

실습 코드 실습 및 검증 코드 눌러서 보기접기 
2000 True
1900 False
2024 True
2025 False

and는 두 조건이 모두 참일 때, or는 하나라도 참일 때 참입니다. and가 or보다 우선 적용되지만, 의도를 분명하게 보이기 위해 괄호를 사용했습니다. 이 함수는 연도를 정수로 입력받고 그레고리력 규칙을 적용한다는 전제를 갖습니다.

삼각형과 시간대 판별

세 변으로 삼각형 종류를 판별할 때는 가장 먼저 양의 길이인지, 가장 긴 변이 나머지 두 변의 합보다 짧은지 확인해야 합니다. 단순히 세 변이 같은지만 검사하면 실제로 만들 수 없는 삼각형까지 분류할 수 있습니다.

실습 코드 삼각형의 유효성과 종류 확인 눌러서 보기접기 
def classify_triangle(a, b, c):
    sides = sorted([a, b, c])
    if sides[0] <= 0 or sides[0] + sides[1] <= sides[2]:
        return "삼각형 아님"
    if a == b == c:
        return "정삼각형"
    if a == b or b == c or a == c:
        return "이등변삼각형"
    return "부등변삼각형"

print(classify_triangle(3, 3, 3))
print(classify_triangle(1, 2, 3))

시간 조건에서는 하루의 양끝을 함께 다루는 경우가 많습니다. ‘7시 이전 또는 20시 이후’는 hour < 7 or hour >= 20으로 표현합니다.

실습 코드 야간 시간대와 소음 상태를 함께 검사 눌러서 보기접기 
def check_quiet_hours(crying, hour):
    if not 0 <= hour <= 23:
        raise ValueError("시간은 0~23 사이여야 합니다.")
    if crying == 1 and (hour < 7 or hour >= 20):
        return "조용히 해!"
    return "조용하군"

print(check_quiet_hours(1, 22))
print(check_quiet_hours(1, 14))

예상 출력

실습 코드 실습 및 검증 코드 눌러서 보기접기 
조용히 해!
조용하군

여기서 괄호를 빼고 crying == 1 and hour < 7 or hour >= 20으로 작성하면 20시 이후에는 crying이 0이어도 조건이 참이 됩니다. 우선순위에 따라 의미가 달라지는 대표적인 오류입니다.

4. 자주 하는 실수와 디버깅

첫째, 입력 타입을 확인하지 않는 실수입니다. "10" + 5는 정수와 문자열을 더하려 하므로 TypeError가 발생합니다. 숫자로 해석할 수 있는 문자열인지 확인하고 int("10") + 5로 바꿉니다.

둘째, =와 ==를 혼동하는 실수입니다. if score = 90:은 문법 오류입니다. 조건 비교에는 == 또는 >= 같은 비교 연산자를 사용해야 합니다.

셋째, 조건 순서를 잘못 배치하는 실수입니다. 점수가 90점 이상인 조건보다 70점 이상인 조건을 앞에 두면 높은 점수가 낮은 등급에 먼저 들어갑니다. 배타적인 분기에서는 보통 더 구체적인 조건부터 검사합니다.

넷째, 테스트 입력이 정상 사례에만 치우치는 문제입니다. 시간 계산은 자정 직전과 직후, 윤년은 1900·2000처럼 세기 경계, 삼각형은 1, 2, 3처럼 성립하지 않는 입력도 시험해야 합니다. 이런 경계값 테스트가 숨은 실수를 찾아줍니다.

5. 실제 활용 — 기초 문법이 개발로 연결되는 순간

정수 계산과 조건 분기는 작은 연습 문제에서만 사용되는 것이 아닙니다. 타이머의 시간 표시, 날짜 처리의 일부, 사용자 입력 검증, 데이터 전처리의 조건부 분류처럼 실제 프로그램의 중요한 구성 요소입니다.

예를 들어 AI 모델에 넣을 데이터를 정리할 때도 값이 숫자형인지 문자열인지, 누락되거나 범위 밖인 값이 있는지 판단해야 합니다. 다만 데이터 분석에서는 Python 기본 문법뿐 아니라 NumPy·Pandas와 같은 도구의 자료형 및 결측치 처리 규칙도 따로 익혀야 합니다.

6. 핵심 정리와 복습

이번 글에서는 Python 실행 환경, 들여쓰기, 객체를 참조하는 변수, 자료형과 형 변환, 연산자, 조건문의 흐름을 다뤘습니다. 특히 입력 → 자료형 확인 → 계산 → 조건 판단 → 결과 검증 순서로 생각하면 여러 유형의 기초 문제를 체계적으로 해결할 수 있습니다.

MY KEY FINDINGS 이번 글의 핵심 정리
  • Python의 변수는 객체를 참조하는 이름이며, 대입(=)과 비교(==)는 서로 다른 역할을 합니다.
  • input()이 반환한 문자열을 숫자로 사용할 때는 입력 형식을 확인하고 적절히 형 변환해야 합니다.
  • 시간 및 자릿수 문제는 단위를 통일한 뒤 //와 %로 분해하면 간결하게 해결할 수 있습니다.
  • 조건문은 분기 순서와 논리 연산자의 우선순위를 함께 고려해야 합니다.
