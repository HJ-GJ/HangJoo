Python 처음 시작하기 · 3/3편
계산과 비교 연산을 익히고 if·else·elif의 실행 흐름과 흔한 실수를 확인합니다.

3. 확인 · 연산자와 조건문 이해하기

3-1. 연산자로 계산하기

기호 의미 예시와 결과
+ 더하기 7 + 3 → 10
- 빼기 7 - 3 → 4
* 곱하기 7 * 3 → 21
/ 나누기 7 / 2 → 3.5
// 내림한 몫 7 // 2 → 3
% 나머지 7 % 2 → 1
** 거듭제곱 2 ** 3 → 8

//는 양수 계산에서 보통 정수 몫처럼 보이지만, 정확히는 아래쪽(음의 무한대 방향)으로 내림합니다. 예를 들어 -7 // 3의 결과는 -3입니다.

3-2. =와 ==는 다릅니다

=는 대입, ==는 두 값이 같은지 비교하는 기호입니다. 비교 결과는 True 또는 False입니다.

score = 80
print(score == 80)
print(score >= 90)

예상 출력

True
False

3-3. if는 언제 사용할까?

if는 어떤 조건이 참일 때만 코드를 실행하는 조건문입니다. Python은 콜론(:)과 들여쓰기로 코드를 묶습니다.

age = 26

if age >= 20:
    print("성인입니다.")

print("확인 종료")

예상 출력

성인입니다.
확인 종료

첫 번째 print()는 조건이 참일 때만, 들여쓰지 않은 마지막 print()는 조건과 상관없이 실행됩니다.

else를 사용하면 조건이 거짓일 때 실행할 코드를 정할 수 있습니다.

score = 55

if score >= 60:
    print("합격입니다.")
else:
    print("다음에 다시 도전해 봅시다.")

예상 출력: 다음에 다시 도전해 봅시다.

elif는 조건을 위에서부터 추가로 검사할 때 사용합니다.

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

print(grade)

예상 출력: B

처음 참인 조건 하나만 실행하기 때문에 조건을 작성한 순서도 중요합니다. and는 두 조건을 함께 만족하는지, or는 둘 중 하나라도 만족하는지 확인할 때 사용합니다. not은 참과 거짓을 반대로 바꿉니다. 처음에는 조건 하나부터 연습한 뒤 조합해 보세요.

  1. print("Hello", "World", sep="-")는 무엇을 출력할까요?
  2. input()으로 받은 숫자에 바로 1을 더하면 왜 문제가 될까요?
  3. score = 75일 때 if score >= 80: 아래의 코드는 실행될까요?

3-5. 처음에 자주 겪는 실수 세 가지

1. 입력받은 문자열을 숫자로 착각하기

age = "26"
# print(age + 1)  # 문자열과 정수를 더하므로 TypeError
print(int(age) + 1)

예상 출력: 27

오류가 나는 코드는 주석 처리했습니다. 숫자처럼 보이는 입력도 문자열인지 먼저 확인해 보세요.

2. 대입(=)과 비교(==)를 혼동하기

score = 90

if score == 90:
    print("90점입니다.")

예상 출력: 90점입니다.

score = 90은 저장하는 문장이고, score == 90은 조건의 참·거짓을 확인하는 비교식입니다.

3. 들여쓰기 때문에 실행 범위를 바꿔 버리기

score = 50

if score >= 60:
    print("합격입니다.")

print("검사가 끝났습니다.")

예상 출력: 검사가 끝났습니다.

첫 번째 출력은 조건이 거짓이므로 실행되지 않지만, 들여쓰지 않은 마지막 출력은 실행됩니다. Python에서는 들여쓰기 자체가 코드의 구조입니다.

4. 정리 · 첫 번째 공부 기록

이번에는 Python이 무엇인지부터 시작해 출력 → 변수와 입력 → 자료형과 형 변환 → 계산 → 조건문까지 살펴봤습니다.

  • Python과 VS Code: 하나는 실행 환경, 하나는 코드 편집 도구
  • print()와 input(): 출력하고 사용자 입력받기
  • 변수와 자료형: 값을 이름으로 다루고 숫자·문자열 구별하기
  • int(): 숫자로 된 문자열을 정수로 바꾸기
  • if·elif·else: 조건에 따라 다른 코드 실행하기

복습해 볼 순서: print("Hello World!") 작성 → 변수에 값 저장 → input()으로 입력받기 → int()로 형 변환 → if로 분기하기. 처음에는 이 흐름을 직접 손으로 작성해 보는 것으로 충분합니다.
