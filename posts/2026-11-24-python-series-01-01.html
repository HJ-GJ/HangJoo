Python 처음 시작하기 · 1/3편
프로그래밍 언어와 실행 환경의 차이를 알고 Python의 print()로 첫 출력을 확인합니다.

컴퓨터에게 “3과 5를 더한 결과를 화면에 보여 줘”라고 말하면 어떻게 될까요?

우리는 문장의 뜻을 이해하지만, 일반적인 컴퓨터 프로그램은 사람의 말을 그대로 명령으로 받아 실행하지는 못합니다. 컴퓨터가 일을 하려면 무엇을 계산하고 어디에 보여 줄지 정해진 규칙에 맞게 표현한 명령이 필요합니다.

그 명령을 사람이 읽고 작성하기 편하도록 만드는 방법 중 하나가 프로그래밍 언어입니다. Python으로 첫 명령을 적어 보는 것부터 시작해 봅시다.

1. 개념 · Python과 처음 만나는 코드

1-1. 프로그래밍 언어란 무엇일까?

우리가 쓰는 한국어나 영어는 일상적인 뜻을 전달하는 데 편리합니다. 하지만 “조금 더 크게 보여 줘”, “계산해 줘”처럼 말만 하면 일반적인 컴퓨터 프로그램은 어떤 값을 어떻게 처리해야 하는지 정확하게 알 수 없습니다.

컴퓨터의 프로세서는 최종적으로 기계 명령을 실행합니다. 사람이 그 명령을 직접 작성하기는 불편하므로, 프로그래밍 언어로 작업 순서를 코드에 적고 실행 환경이 그 코드를 처리하도록 합니다.

예를 들어 “3과 5를 더해서 결과를 보여 주기”를 Python에서는 이렇게 표현할 수 있습니다.

print(3 + 5)

예상 출력

8

이 코드 한 줄을 작게 나눠 볼까요?

  • 3 + 5: 더하기 계산을 합니다.
  • print(...): 괄호 안에 전달한 값이나 계산 결과를 화면에 보여 줍니다.
  • 8: 계산한 뒤 화면에서 확인할 수 있는 값입니다.

즉, 사람이 하려는 일 → Python 코드 → Python 실행 환경 → 화면의 결과로 이어지는 것입니다. Python 코드 자체가 곧 기계어인 것은 아니며, 실행 환경이 필요한 처리를 거쳐 컴퓨터가 작업하도록 합니다.

1-2. Python은 어떤 언어일까?

Python(파이썬)은 사람이 읽기 비교적 쉬운 문법을 가진 프로그래밍 언어입니다. 계산을 자동화하거나 데이터를 정리하고, 웹 서비스나 인공지능 프로그램을 만드는 일 등 다양한 분야에서 쓰입니다.

Python 코드를 작성한 뒤 실행하면, Python 실행 환경이 코드를 읽고 처리해 결과를 만들어 줍니다. 그래서 처음에는 Python의 문법과 실행 방법을 차근차근 익히는 것이 중요합니다. 구현 방식에 따라 내부 처리 과정에는 여러 단계가 있을 수 있습니다.

1-3. Python과 VS Code는 무슨 차이일까?

도구 하는 일
Python 실제 코드를 실행하는 환경
VS Code 코드를 편하게 작성·수정하는 편집기

직접 코드를 실행하려면 Python 공식 사이트에서 Python을 설치한 뒤, VS Code 같은 편집기로 파일을 작성할 수 있습니다.

  1. Python을 설치합니다. Windows에서는 설치 중 실행 경로(PATH) 관련 옵션을 확인합니다.
  2. 터미널에서 python --version으로 설치를 확인합니다. 일부 환경에서는 python3 --version을 사용합니다.
  3. VS Code에서 새 파일을 만들고 **hello.py**로 저장합니다. .py는 Python 소스 파일 확장자입니다.
  4. 다음 코드를 입력하고 터미널에서 python hello.py를 실행합니다. VS Code에서도 실행 환경을 선택해 실행할 수 있습니다.
print("Hello World!")

예상 출력

Hello World!

처음 헷갈리는 부분: VS Code만 설치했다고 Python 실행 환경까지 자동으로 준비되는 것은 아닙니다. 실행 명령을 인식하지 못한다면 Python 설치와 PATH 설정을 확인해 보세요.

1-4. 화면에 글자를 보여주는 print()

print()는 값을 출력하는 함수입니다. 글자는 따옴표로 감싸고 숫자는 그대로 쓸 수 있습니다.

print("안녕하세요!")
print(2026)
print("Python", "공부")

예상 출력

안녕하세요!
2026
Python 공부

print()는 기본적으로 출력 후 줄을 바꿉니다. 여러 문장을 이어서 출력하고 싶다면 end를, 여러 값을 구분하는 방식을 바꾸고 싶다면 sep를 사용할 수 있습니다.

print("Hello", end=", ")
print("Python")
print("A", "B", sep=" / ")

예상 출력

Hello, Python
A / B

여기까지가 첫 출력입니다. 이제 출력할 내용을 변수에 저장하고, 직접 입력받는 방법으로 넘어가 봅시다.
