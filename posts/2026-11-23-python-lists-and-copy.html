Python 리스트와 복사

이 페이지는 예전에 공개했던 긴 통합 원문입니다. 아래에서 주제별로 나눈 짧은 시리즈를 읽을 수 있어요.

  1. 01리스트·인덱싱·슬라이싱↗
  2. 02리스트에 추가·삭제하고 순회하기↗
  3. 03참조·얕은 복사·깊은 복사↗

앞서 반복문 for와 while을 배울 때, 과일 이름이 담긴 리스트에서 값을 하나씩 꺼내 출력하는 예제를 살펴봤습니다. 그렇다면 그 리스트를 직접 만들고, 필요한 값을 골라내거나 수정하려면 어떻게 해야 할까요? 리스트를 다른 변수에 저장했는데 원본까지 함께 바뀌는 현상은 왜 생길까요?

이번에는 여러 값을 하나로 관리하는 **리스트(List)**의 기본 구조를 먼저 이해하고, 인덱싱·슬라이싱과 추가·삭제 메서드를 연습합니다. 마지막으로 참조, 얕은 복사, 깊은 복사를 비교하면서 어느 연산이 원본에 영향을 주는지 차근차근 정리해 봅니다.

1. 개념 · 리스트는 왜 필요할까?

1-1. 여러 값을 하나로 관리하기

시험 점수 세 개를 저장한다고 생각해 보겠습니다.

score1 = 85
score2 = 90
score3 = 78

세 명이라면 이렇게 변수 세 개를 사용해도 괜찮습니다. 하지만 학생이 100명으로 늘어나면 변수 이름을 일일이 만들고 합계나 평균을 구하기가 불편해집니다. 이때 여러 값을 순서대로 저장할 수 있는 자료형이 리스트입니다.

scores = [85, 90, 78]

print(scores)
print(len(scores))

예상 출력

[85, 90, 78]
3
  • scores = [85, 90, 78]는 대괄호 [] 안에 값 세 개를 쉼표로 구분해 저장합니다.
  • print(scores)는 리스트 전체를 보여 줍니다.
  • len(scores)는 요소(element)의 개수인 3을 반환합니다. 리스트의 번호가 아니라 길이를 구하는 함수입니다.

리스트에는 숫자뿐 아니라 문자열, 불리언 값, 다른 리스트도 넣을 수 있습니다.

student = ["HangJoo", 27, True]
print(student)

예상 출력

['HangJoo', 27, True]

파이썬은 서로 다른 자료형을 한 리스트에 담을 수 있지만, 실제로 여러 사람의 점수를 관리한다면 점수끼리 묶는 등 각 요소의 의미를 일관되게 유지하는 편이 이해하기 쉽습니다.

1-2. 리스트는 순서가 있고, 값을 바꿀 수 있다

리스트를 배울 때 기억할 성질은 두 가지입니다. 첫째, 순서가 있어 위치로 접근할 수 있습니다. 둘째, 리스트는 **가변 객체(mutable object)**라서 생성한 후에도 특정 요소를 바꿀 수 있습니다.

scores = [85, 90, 78]
scores[1] = 100
print(scores)

예상 출력

[85, 100, 78]

scores[1]은 두 번째 점수를 뜻합니다. 그 위치에 100을 대입해 기존 리스트의 요소를 변경했습니다. 리스트 자체를 수정했다는 사실이 뒤의 복사 개념에서 중요해집니다.

1-3. 인덱싱: 원하는 요소 하나 선택하기

리스트의 각 위치에 붙은 번호를 **인덱스(index)**라고 합니다. 파이썬에서는 첫 번째 요소의 인덱스가 0입니다. 음수 인덱스를 이용하면 뒤에서부터 셀 수도 있습니다.

값 85 90 78 95
양수 인덱스 0 1 2 3
음수 인덱스 -4 -3 -2 -1 
scores = [85, 90, 78, 95]

print(scores[0])
print(scores[2])
print(scores[-1])

예상 출력

85
78
95

scores[0]은 첫 번째 값, scores[2]는 세 번째 값, scores[-1]은 맨 마지막 값입니다. [-1]을 사용하면 리스트 길이를 미리 계산하지 않고 마지막 요소에 접근할 수 있습니다.

주의: 요소가 4개일 때 사용할 수 있는 양수 인덱스는 0부터 3까지입니다. scores[4]는 범위를 벗어나 IndexError를 발생시킵니다. 빈 리스트에 [-1]을 사용해도 같은 오류가 발생합니다.

1-4. 슬라이싱: 여러 요소를 한꺼번에 선택하기

인덱싱이 요소 하나를 가져온다면, 슬라이싱(slicing)은 범위를 선택합니다. 기본 형태는 리스트[시작:끝:간격]입니다. 시작은 포함하고 끝은 포함하지 않는다는 규칙이 핵심입니다.

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
print(numbers[:3])
print(numbers[2:])
print(numbers[::2])
print(numbers[::-1])

예상 출력

[20, 30, 40]
[10, 20, 30]
[30, 40, 50]
[10, 30, 50]
[50, 40, 30, 20, 10]
  • [1:4]는 인덱스 1, 2, 3의 값만 가져옵니다.
  • [:3]은 시작을 생략해 처음부터 인덱스 3 직전까지 선택합니다.
  • [2:]는 인덱스 2에서 끝까지 선택합니다.
  • [::2]는 처음부터 두 칸씩 건너뛰며 선택합니다.
  • [::-1]은 음수 간격 -1을 사용해 뒤에서 앞으로 선택합니다.

리스트를 슬라이싱하면 새로운 바깥 리스트가 반환됩니다. 다만 리스트 안에 또 다른 가변 객체가 있다면 그 내부 객체까지 새로 복사되는 것은 아닙니다. 이 차이는 2-5절에서 확인합니다.

2. 실습 · 리스트를 직접 다뤄보기

2-1. 요소를 추가하고 삭제하기

리스트는 할 일 목록처럼 항목이 계속 바뀌는 자료를 다루는 데 잘 어울립니다. 자주 쓰는 메서드 네 가지를 비교해 봅니다.

메서드 하는 일 반환값
append(x) 마지막에 x 한 개 추가 None
insert(i, x) 인덱스 i 위치에 x 삽입 None
pop(i) 인덱스 i의 요소를 제거 제거한 요소
remove(x) 값 x와 같은 첫 번째 요소 제거 None

마지막에 추가하기: append()

tasks = ["Python 공부", "운동"]
tasks.append("독서")
print(tasks)

예상 출력

['Python 공부', '운동', '독서']

append()는 기존 리스트를 직접 변경합니다. 새로운 리스트를 반환하지 않으므로 tasks = tasks.append("독서")처럼 작성하면 tasks에 None이 저장됩니다.

원하는 위치에 삽입하기: insert()

tasks = ["Python 공부", "독서"]
tasks.insert(1, "운동")
print(tasks)

예상 출력

['Python 공부', '운동', '독서']

인덱스 1 자리에 운동을 넣었으므로 기존의 독서가 뒤로 밀립니다. 기존 항목을 덮어쓰는 tasks[1] = "운동"과 다르게 항목이 하나 늘어납니다.

꺼내면서 제거하기: pop()

tasks = ["Python 공부", "운동", "독서"]
finished = tasks.pop(0)
print(finished)
print(tasks)

예상 출력

Python 공부
['운동', '독서']

pop(0)은 첫 번째 요소를 제거하면서 그 값을 돌려줍니다. 인덱스를 생략한 pop()은 마지막 요소를 꺼냅니다. 비어 있는 리스트에서 호출하면 IndexError가 발생합니다.

값으로 찾아서 제거하기: remove()

tasks = ["Python 공부", "운동", "독서", "운동"]
tasks.remove("운동")
print(tasks)

예상 출력

['Python 공부', '독서', '운동']

remove()는 위치가 아니라 값으로 삭제합니다. 같은 값이 여러 번 등장해도 처음 발견한 한 개만 삭제하며, 찾는 값이 없다면 ValueError가 발생합니다.

2-2. 앞에서 배운 for로 리스트 순회하기

NO.02에서 배운 반복문을 리스트와 연결하면 모든 점수를 하나씩 처리할 수 있습니다. for score in scores:에서 score는 리스트에서 이번 차례에 꺼낸 요소입니다.

scores = [85, 90, 78]

total = 0
for score in scores:
    total += score

print("합계:", total)
print("평균:", total / len(scores))

예상 출력

합계: 253
평균: 84.33333333333333

total = 0으로 합계의 시작값을 준비합니다. for문 안에서는 85, 90, 78을 차례로 더해 253을 만들고, 반복문이 끝난 뒤 len(scores)인 3으로 나눕니다. 같은 계산은 sum(scores) / len(scores)로 짧게 작성할 수도 있습니다. 빈 리스트의 평균은 len(scores)가 0이므로 별도의 예외 처리가 필요합니다.

2-3. 대입은 복사가 아니다: 같은 객체를 가리키는 두 이름

먼저 다음 결과를 출력 전에 예상해 봅니다.

original = [10, 20, 30]
copied = original
copied[0] = 999

print(original)
print(copied)
print(original is copied)

예상 출력

[999, 20, 30]
[999, 20, 30]
True

copied = original은 새 리스트를 만드는 코드가 아닙니다. 두 변수 이름이 메모리의 같은 리스트 객체를 참조하게 합니다. 그래서 copied[0] = 999로 변경하면 original을 통해서도 같은 결과가 보입니다.

original ──┐
           ├──> [10, 20, 30]  (같은 객체 한 개)
copied   ──┘

이때 original is copied는 True입니다. is는 두 이름이 정확히 같은 객체를 가리키는지 검사합니다.

2-4. is와 ==: 같은 객체일까, 같은 값일까?

==는 두 객체의 값이 같은지, is는 두 이름이 같은 객체를 가리키는지 확인합니다.

a = [10, 20]
b = a.copy()

print(a == b)
print(a is b)

예상 출력

True
False

a와 b의 내용은 [10, 20]으로 같지만, copy()가 새 리스트를 만들었기 때문에 두 리스트는 다른 객체입니다. 값의 동등성을 확인할 때는 보통 ==를 사용하고, 같은 객체인지 알아야 할 때 is를 사용합니다.

2-5. 얕은 복사: 바깥 리스트는 새로, 내부 참조는 공유

새로운 리스트를 만들 때는 copy()나 [:]를 사용할 수 있습니다. 이 방식은 **얕은 복사(shallow copy)**입니다. 바깥 리스트는 별도 객체가 되지만, 요소가 다른 리스트를 가리키고 있다면 그 내부 리스트 자체는 공유합니다.

original = [[10, 20], [30, 40]]
copied = original.copy()
copied[0][0] = 999

print(original)
print(copied)
print(original is copied)
print(original[0] is copied[0])

예상 출력

[[999, 20], [30, 40]]
[[999, 20], [30, 40]]
False
True

첫 번째 False는 바깥 리스트가 서로 다르다는 뜻입니다. 두 번째 True는 첫 번째 내부 리스트를 공유한다는 뜻입니다. 따라서 copied[0][0] = 999로 내부 리스트 안의 값을 바꾸면 원본에서도 그 변화를 관찰합니다.

그렇다면 복사본의 첫 번째 내부 리스트를 통째로 교체하면 어떻게 될까요?

original = [[10, 20], [30, 40]]
copied = original.copy()
copied[0] = [999, 20]

print(original)
print(copied)

예상 출력

[[10, 20], [30, 40]]
[[999, 20], [30, 40]]

이번에는 copied[0]이라는 바깥 리스트의 한 칸을 다른 객체로 교체했습니다. 바깥 리스트가 서로 독립적이므로 원본의 첫 번째 칸은 바뀌지 않습니다. 이 차이를 이해하면 얕은 복사를 제대로 사용할 수 있습니다.

2-6. 깊은 복사: 중첩된 리스트도 독립적으로

중첩된 가변 객체까지 독립적으로 복사할 필요가 있다면 표준 라이브러리 copy 모듈의 deepcopy()를 사용합니다.

import copy

original = [[10, 20], [30, 40]]
copied = copy.deepcopy(original)
copied[0][0] = 999

print(original)
print(copied)
print(original[0] is copied[0])

예상 출력

[[10, 20], [30, 40]]
[[999, 20], [30, 40]]
False

import copy는 복사 관련 함수를 담은 표준 라이브러리 모듈을 가져옵니다. copy.deepcopy(original)은 바깥 리스트뿐 아니라 첫 번째·두 번째 내부 리스트도 별도로 생성하기 때문에, copied[0][0] = 999가 원본에 영향을 주지 않습니다.

다만 deepcopy()가 세상의 모든 객체를 무조건 완전히 새로 생성한다는 뜻은 아닙니다. 변경 불가능한 객체는 그대로 공유할 수 있고, 파일·외부 연결 등의 일부 객체는 일반적인 방식으로 복사할 수 없습니다. 일반적인 중첩 리스트 예제에서는 내부의 가변 리스트까지 분리된다고 이해하면 충분합니다.

직접 실험해 보기: 다음 실험실에서 대입, 얕은 복사, 깊은 복사 버튼을 바꿔 보고, 내부 값 변경과 내부 리스트 교체를 각각 눌러 보세요. 어느 경우에 original이 바뀌는지 확인할 수 있습니다.

3. 확인 · 실수하기 쉬운 부분

3-1. 인덱스와 슬라이싱의 경계

numbers = [10, 20, 30]

# print(numbers[3])  # IndexError: 존재하지 않는 위치
print(numbers[1:3])
print(numbers[100:200])

예상 출력

[20, 30]
[]

인덱싱은 범위를 벗어나면 오류를 내지만, 슬라이싱으로 범위 밖을 선택하면 가능한 범위만 반환합니다. [100:200]처럼 해당 구간에 아무 값도 없다면 빈 리스트가 나옵니다. numbers[::0]처럼 간격을 0으로 지정하면 ValueError가 발생하므로 조심해야 합니다.

3-2. 메서드의 반환값과 제거 대상

numbers = [10, 20]
result = numbers.append(30)

print(result)
print(numbers)

예상 출력

None
[10, 20, 30]

append()는 리스트를 수정하고 None을 반환하므로, 수정된 리스트를 결과 변수에 다시 대입하지 않아야 합니다. pop()은 위치를, remove()는 값을 기준으로 제거한다는 점도 구분해 두면 좋습니다.

3-3. 중첩 리스트를 만들 때 같은 행을 반복해서 참조하는 실수

복사 개념은 2차원 리스트에서도 등장합니다. 다음 코드는 겉으로는 두 행을 만든 것처럼 보여도 실제로는 같은 내부 리스트를 두 번 참조합니다.

board = [[0] * 3] * 2
board[0][0] = 1
print(board)

예상 출력

[[1, 0, 0], [1, 0, 0]]

첫 행만 바꾼 것 같은데 둘째 행도 변경되었습니다. 서로 독립적인 행이 필요하다면 반복할 때마다 새로운 내부 리스트를 만들면 됩니다.

board = [[0] * 3 for _ in range(2)]
board[0][0] = 1
print(board)

예상 출력

[[1, 0, 0], [0, 0, 0]]

여기서 [0] * 3은 각각의 행 안에 정수 0 세 개를 만드는 용도이고, 바깥쪽의 for가 행마다 새 리스트를 생성합니다. 리스트 컴프리헨션의 자세한 문법은 뒤의 학습에서 더 설명할 예정입니다.

4. 정리 · 학습 점수 관리에 활용하기

4-1. 리스트를 이용한 작은 점수 관리 프로그램

지금까지 다룬 개념을 간단한 프로그램 하나로 연결해 봅시다. 아래 코드는 점수를 추가하고 일부를 선택한 뒤, 별도의 백업 리스트를 만들고 최솟값과 평균을 계산합니다.

scores = [80, 95, 70, 88]

# 1. 새로운 점수 추가
scores.append(92)

# 2. 앞의 세 점수만 새 리스트로 선택
first_three = scores[:3]

# 3. 원본의 현재 상태를 백업
backup = scores.copy()

# 4. 최솟값과 평균 계산
lowest = min(scores)
average = sum(scores) / len(scores)

print("전체 점수:", scores)
print("앞의 세 점수:", first_three)
print("백업:", backup)
print("최저 점수:", lowest)
print("평균:", average)

# 5. 이후 원본을 변경해도 백업은 독립적
scores[0] = 100
print("수정 후:", scores)
print("백업 유지:", backup)

예상 출력

전체 점수: [80, 95, 70, 88, 92]
앞의 세 점수: [80, 95, 70]
백업: [80, 95, 70, 88, 92]
최저 점수: 70
평균: 85.0
수정 후: [100, 95, 70, 88, 92]
백업 유지: [80, 95, 70, 88, 92]

처음에 append(92)로 다섯 번째 점수를 추가합니다. scores[:3]은 앞의 세 점수를 담는 별도 리스트를 만들고, scores.copy()도 바깥 리스트를 별도로 만듭니다. 최솟값은 min(), 합계는 sum(), 개수는 len()으로 계산하므로 평균은 (80 + 95 + 70 + 88 + 92) / 5 = 85.0입니다.

마지막 두 줄을 보면 scores[0] = 100으로 원본을 변경했지만 백업은 수정 이전 값을 유지합니다. 예제의 요소는 숫자이므로 얕은 복사로도 별도 백업이 가능했지만, 중첩된 가변 데이터를 다룰 때는 2-5절처럼 내부 공유 여부를 확인해야 합니다. 여기의 backup은 메모리 안의 별도 리스트일 뿐, 파일에 영구 저장한 백업은 아닙니다.

4-2. 핵심 개념 한눈에 정리하기

개념 기억할 점
리스트 [] 여러 값을 순서대로 저장하며 요소 수정 가능
len() 리스트 안의 요소 개수
인덱싱 a[i] 특정 위치 하나 선택, 첫 인덱스는 0
슬라이싱 a[start:end:step] 시작은 포함, 끝은 제외; 바깥 리스트는 새로 생성
append() / insert() 기존 리스트에 요소 추가
pop() / remove() 위치 기준 / 값 기준으로 제거
b = a 새 리스트가 아니라 같은 객체 참조
a == b / a is b 값 비교 / 객체 동일성 비교
a.copy() 또는 a[:] 얕은 복사: 바깥 리스트는 새로, 중첩 객체 참조는 공유
copy.deepcopy(a) 일반적인 중첩 가변 리스트까지 새로 복사

리스트에서 가장 중요한 것은 메서드 이름을 외우는 것보다 어떤 동작이 기존 객체를 바꾸고, 어떤 동작이 새 객체를 만드는지 이해하는 것입니다. 이 원리를 익혀 두면 다음에 함수 인자, 2차원 리스트, 클래스의 속성, 데이터 처리 코드를 배울 때도 예상하지 못한 값 변경을 더 쉽게 찾아낼 수 있습니다.
